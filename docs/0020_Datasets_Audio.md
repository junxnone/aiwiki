# Audio

音频相关的常用数据集，待补充。常见类别：

| 任务 | 常用数据集 | 说明 |
| --- | --- | --- |
| 语音识别 | LibriSpeech | 英文有声书朗读语料，大规模、带转写文本 |
| 音频事件分类 | AudioSet | Google 的大规模音频事件标注数据（来自 YouTube 视频） |
| 环境声分类 | ESC-50 | 50 类环境声音的小型数据集 |
| 音乐 | GTZAN | 音乐流派分类的经典小数据集 |

表中：

- **任务**：数据集面向的问题；**说明**：数据集的特点
- 对比结论：做语音识别用 LibriSpeech 一类带转写文本的语料；做声音事件检测则用 AudioSet 类的事件标注数据

相关基础见 [Audio Basics](https://github.com/junxnone/aiwiki/issues/775)。其他类型的数据集见 [Datasets](https://github.com/junxnone/aiwiki/issues/17)。
