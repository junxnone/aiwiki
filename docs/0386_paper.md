## 读论文的方法

| 步骤 | 做什么 |
| --- | --- |
| 1 | 读摘要、图和结论，判断是否相关 |
| 2 | 看方法部分，弄清「输入、输出、核心模块、损失」 |
| 3 | 记录关键公式和变量含义 |
| 4 | 看实验，记录数据集、指标和对比结论 |
| 5 | 记下局限与可改进点 |

表中：对比结论：先快速筛选，再精读有价值的论文。
