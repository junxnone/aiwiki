## 对比

| 工具 | 语言 | 特点 |
| --- | --- | --- |
| [PCL](https://github.com/junxnone/aiwiki/issues/77) | C++ | 功能全面的点云库：滤波、配准、分割、重建等 |
| Open3D | C++ / Python | 现代化的 3D 数据处理库，Python 接口友好，含可视化与配准、重建 |

表中：对比结论：C++ 工程和完整算法选 PCL；快速原型和 Python 工作流选 Open3D。
