# 3D Cloud 点云

> 点云处理专题索引——覆盖坐标变换、预处理（降采样/离群点移除/拼接配准）、特征描述子几大块经典（非深度学习）点云处理技术。点云相关的更广泛上下文（点云工具链、应用场景）见 [3D](0076_3D)；深度学习路线（PointNet 系列、点云检测/分割网络）见 [3D 深度学习技术综述](0233_3D_DL)。

## 坐标变换

- [旋转矩阵 Rotation Matrix](0234_3D_Cloud_RM)：点云刚体变换（旋转+平移）的 4x4 齐次矩阵表示，是配准、拼接等后续操作的基础工具。

## 预处理

- [降采样 Sampling](0285_3D_Cloud_Sampling)：在尽量保留几何信息的前提下减少点的数量，常见于配准/实时处理前。
- [离群点移除 SOR](0287_3D_Cloud_SOR)：基于统计分布（StatisticalOutlierRemoval）或半径邻域（RadiusOutlierRemoval）剔除噪声点。
- [点云拼接 Merge](0286_3D_Cloud_Merge)：把多份点云融合进统一坐标系，核心是配准（经典 ICP/PPF 见 [3D](0076_3D)，深度学习版本见 [3D 深度学习技术综述](0233_3D_DL)）。

## 特征描述子

- [Features 总览](0424_3D_Cloud_Features)：曲率、PFH、FPFH、ISS 等局部几何特征描述子汇总与对比，用于点云配准时的关键点检测和对应点匹配。

## 处理流程里的位置

一个典型的点云配准/拼接流程大致是：**降采样**（减少计算量）→ **离群点移除**（去噪）→ **特征描述/关键点检测**（为配准找对应点）→ **配准计算变换矩阵**（见 [旋转矩阵](0234_3D_Cloud_RM)）→ **拼接融合**（见 [点云拼接](0286_3D_Cloud_Merge)）——上面几篇子章节分别对应这条流程里的一个环节。
