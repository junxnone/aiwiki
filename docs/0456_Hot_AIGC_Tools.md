# AIGC Tools

AIGC（AI Generated Content，人工智能生成内容）工具：用生成模型自动生成图像、动画等内容。

## 图像生成
- Stable Diffusion
- Midjourney
- DALL-E
- ImageGen
- 豆包
- 其他国产大模型...

## 动画生成
- AnimateDiff

## 对比

| 工具 | 类型 | 特点 |
| --- | --- | --- |
| Stable Diffusion | 开源模型 | 可本地部署、可微调（见 [Stable Diffusion](https://github.com/junxnone/aiwiki/issues/402)、[SD webui](https://github.com/junxnone/aiwiki/issues/440)） |
| Midjourney | 闭源在线服务 | 画面风格强，通过 Discord 等使用 |
| DALL-E | 闭源 API / 产品 | 与 ChatGPT 等产品结合，文字理解较好 |
| ImageGen | 闭源（Google） | 文生图模型 |
| 豆包等国产大模型 | 在线服务 | 中文提示词友好 |
| AnimateDiff | 开源 | 在 Stable Diffusion 之上加入运动模块，生成短动画 |

表中：

- **类型**：开源可本地运行，还是闭源通过服务使用；**特点**：该工具的主要优势
- 对比结论：需要可控和可微调选 Stable Diffusion 系；追求开箱即用的效果选在线服务

- 图像编辑：[DragGAN](https://github.com/junxnone/aiwiki/issues/429)、[LaMa](https://github.com/junxnone/aiwiki/issues/404)
