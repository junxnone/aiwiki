## 0. 先看全景

**判别式**模型学习"给定历史，预测一个值或几个分位数"；**生成式**模型学习整个条件分布 $p(\mathbf y_{t+1:t+H}\mid \mathbf y_{1:t},\mathbf c)$ 或联合分布 $p(\mathbf y_{1:T})$，因而能**采样**出许多条合理的未来路径、补全缺失、或凭空生成新序列。

| 任务 | 生成式的做法 | 代表方法 | 本文章节 |
|---|---|---|---|
| 概率预测 | 对未来路径采样或输出灵活分布，再取分位数 | DeepAR 类参数化分布、IQN、条件流、TimeGrad、TSDiff、Sundial | §3.1、§3.4–§3.6 |
| 缺失值填补 | 条件于已观测值，采样缺失部分 | CSDI、SSSD、GP-VAE | §3.2、§3.5 |
| 合成数据 | 无条件生成与真实序列同分布的序列 | TimeVAE、TimeGAN、Diffusion-TS、TSDiff | §3.2、§3.3、§3.5、§3.8 |
| 异常检测 | 以密度或重构误差作为异常分数 | 重构类生成模型 | §3.7 |

一句话定位：**生成式的价值不在点预测更准，而在表达复杂的分布与依赖结构，并支持采样**。代价是训练更难、采样更慢、评估更复杂。很多业务只需要"几个分位数"，此时分位数回归加共形校准往往已足够（§6）。

读完本文你应能回答：为什么概率预测需要生成式模型、五类生成模型（参数化分布、VAE、GAN、流、扩散）各自的原理与代价、TimeGrad 与 CSDI 的区别、什么时候该用扩散而不是分位数回归、合成数据怎么评估。

## 1. 基石概念

### 1.1 判别式与生成式

- **判别式**：学习 $\hat y=f(\mathbf x)$，或若干分位数 $\hat q^{\tau}=f_\tau(\mathbf x)$（见[机器学习篇 §3.3](0605_ML_Tasks_TimeSeries_ML)）。
- **生成式**：学习分布 $p_\theta(\mathbf y\mid\mathbf x)$，由它**采样**得到 $\mathbf y^{(1)},\dots,\mathbf y^{(S)}$，再统计均值、分位数、路径相关性等任意量。

**关键差别**：分位数回归给出的是**每个时间点的边缘分位数**，各点之间的**联合依赖**（例如"如果第一天销量高，第二天也倾向高"）不能保证；生成式模型采样出的是整条路径，保留这种依赖。对于需要**路径级量**的决策（如累计需求、峰值时刻、排程），这一点很重要 [经验]。

### 1.2 自回归分解与联合建模

联合分布可用链式法则分解：

$$p(\mathbf y_{1:T})=\prod_{t=1}^{T}p\bigl(\mathbf y_t\mid \mathbf y_{<t}\bigr)$$

| 方式 | 做法 | 代表 |
|---|---|---|
| **自回归** | 每步一个条件分布，逐步采样 | DeepAR、TimeGrad |
| **非自回归 / 整段生成** | 一次生成整个预测窗口或整条序列 | CSDI、TSDiff、Diffusion-TS、条件流（对整窗） |

自回归容易训练、可处理任意长度，但有**误差累积**，且逐步采样慢；整段生成避免累积，但需要为整个窗口的联合分布建模。

### 1.3 条件生成与无条件生成

- **条件模型**为特定任务（预测或填补）训练，条件信息作为输入（CSDI 的观测、TimeGrad 的 RNN 状态）；
- **无条件模型**学习序列本身的分布，下游任务在推理时通过**引导**（guidance）实现条件化，如 TSDiff 的自引导（§3.5）。无条件模型更通用，一个模型可服务预测、填补、合成多个任务。

### 1.4 评估生成模型

| 任务 | 指标 | 说明 |
|---|---|---|
| 概率预测 | CRPS、加权分位数损失、覆盖率；多变量用路径或能量类指标（如对各维求和后的 CRPS，具体定义待核实） | 定义见 [metrics §2](0610_ML_Tasks_TimeSeries_Metrics)；先看校准，再比锐度 |
| 填补 | 被遮盖位置的 MAE/RMSE，概率填补用 CRPS | 遮盖方式要模拟真实缺失（连续缺段，见 [metrics §4.2](0610_ML_Tasks_TimeSeries_Metrics)） |
| 合成数据 | **相似性**（判别式得分：训练一个分类器区分真假，准确率越接近 0.5 越好）、**可用性**（TSTR：在合成数据上训练、在真实数据上测试预测任务的误差）、多样性与可视化 | 指标选择与实现不统一，论文间不一定可比 [经验]；具体定义依各论文，待核实 |

样本数 $S$ 对 CRPS 估计有影响（样本估计公式见[经典篇 §3.15](0604_ML_Tasks_TimeSeries_Classical) 与 [metrics §2.2](0610_ML_Tasks_TimeSeries_Metrics)），比较模型时需固定 $S$ 并报告。

### 1.5 常见困难

| 问题 | 含义 | 常见于 |
|---|---|---|
| **模式坍塌**（mode collapse） | 生成样本多样性不足，只覆盖分布的少数模式 | GAN；Sundial 摘要提到用 TimeFlow Loss 缓解模式坍塌（arXiv:2502.00816 [V]） |
| **采样慢** | 需要多步迭代去噪 | 扩散模型 |
| **似然不可得或难算** | 无法直接比较样本的对数似然 | GAN、扩散（需变分下界） |
| **训练不稳定** | 对抗训练、扩散的噪声调度 | GAN、扩散 |
| **评估不统一** | 合成数据的"好"缺乏统一标准 | 所有生成模型 |

## 3. 各类方法详解

### 3.1 参数化分布与分位数网络

#### 参数化分布输出

模型输出分布参数 $\theta_t=g(h_t)$，以负对数似然训练：

$$\mathcal L=-\sum_{t}\log p\bigl(y_t\mid\theta_t\bigr)$$

常见分布：高斯、Student-t（重尾）、负二项（计数）。DeepAR（[V]）采用这种方式（见[深度篇 §3.1](0606_ML_Tasks_TimeSeries_Deep)）。多变量时需要建模变量间相关：低秩高斯 copula 等做法（待核实）。

| | |
|---|---|
| **优点** | 训练稳定；似然显式；分位数可解析计算 |
| **缺点** | 受分布族限制（单峰、对称等）；多变量联合需额外结构；分布选错会严重失真 |

#### 隐式分位数网络（IQN）

Probabilistic Time Series Forecasting with Implicit Quantile Networks（arXiv:2107.03743 [V]）把自回归 RNN 与**隐式分位数网络**结合：网络以分位水平 $\tau\sim U(0,1)$ 作为输入，输出对应的分位数，以 pinball 损失训练：

$$\mathcal L=\mathbb E_{\tau\sim U(0,1)}\Bigl[L_\tau\bigl(y,\hat q_\tau\bigr)\Bigr]$$

由于 CRPS 等于对所有分位数 pinball loss 的积分（见[经典篇 §3.15](0604_ML_Tasks_TimeSeries_Classical)），这等于直接优化 CRPS。摘要称其在逐点预测精度与估计底层时间分布两方面都有优势。

### 3.2 变分自编码器（VAE）

#### 原理

引入潜变量 $z$，用编码器 $q_\phi(z\mid x)$ 近似后验，以**证据下界**训练：

$$\mathcal L_{\mathrm{ELBO}}=\mathbb E_{q_\phi(z\mid x)}\bigl[\log p_\theta(x\mid z)\bigr]-\mathrm{KL}\bigl(q_\phi(z\mid x)\,\Vert\,p(z)\bigr)$$

第一项是重构，第二项把潜变量分布拉向先验。生成时从先验采样 $z$，由解码器得到序列。

#### 时序中的两个例子

- **TimeVAE**（arXiv:2111.08095 [V]）：用 VAE 做**多变量时间序列生成**，摘要强调三点：**可解释性**、**融入领域知识的能力**、**训练时间短**；在相似性与"用生成数据做下一步预测"两类评估上与 GAN 方法比较，并指出降噪可使生成数据偏离原数据但有助于下一步预测。
- **GP-VAE**（arXiv:1907.04155 [V]）：**深度概率填补**，在潜空间用高斯过程先验刻画时间平滑性（依原文印象，细节待核实）。

| | |
|---|---|
| **优点** | 训练稳定；有显式的潜空间，可做插值、可解释分量（TimeVAE）；训练快 |
| **缺点** | 样本常偏模糊、方差被低估（"降噪"倾向）；KL 项与重构项的权衡敏感；单个高斯潜变量对复杂分布表达有限 |
| **适用** | 合成数据的快速基线、需要潜表示或可解释分量的场景 |

### 3.3 生成对抗网络（GAN）

#### 原理

生成器 $G$ 与判别器 $D$ 对抗：

$$\min_G\max_D\ \mathbb E_{x\sim p_{\text{data}}}\bigl[\log D(x)\bigr]+\mathbb E_{z\sim p_z}\bigl[\log\bigl(1-D(G(z))\bigr)\bigr]$$

时序 GAN（如 TimeGAN，NeurIPS 2019，待核实）在对抗目标之外，通常加入保持时间动态的监督损失与嵌入空间（依原文印象，待核实）。

| | |
|---|---|
| **优点** | 样本可以很逼真；采样一次前向即可，速度快 |
| **缺点** | **训练不稳定**；**模式坍塌**；无显式似然，难以评估；条件概率预测不如扩散与流自然 |
| **适用** | 合成数据；目前在概率预测上被扩散和流超越的趋势明显 [经验] |

### 3.4 归一化流

#### 原理

用一系列**可逆变换** $f$ 把简单分布（如标准高斯）变成复杂分布，对数似然由变量替换公式**精确**给出：

$$\log p_X(x)=\log p_Z\bigl(f^{-1}(x)\bigr)+\log\Bigl\lvert\det\frac{\partial f^{-1}(x)}{\partial x}\Bigr\rvert$$

#### 时序应用

*Multivariate Probabilistic Time Series Forecasting via Conditioned Normalizing Flows*（arXiv:2002.06103 [V]）把**自回归深度模型**与**条件归一化流**结合：自回归部分提供对未来的外推能力，流负责表示高维数据分布，摘要称在含数千条相互作用序列的真实数据集上改进了标准指标。

| | |
|---|---|
| **优点** | **精确似然**；一次前向采样；多变量联合分布可表达；评估直观（NLL） |
| **缺点** | 变换必须可逆且雅可比易算，限制了网络结构；表达力在高维下仍有限；训练需要调结构 |
| **适用** | 需要精确似然、高维多变量联合预测的场景 |

### 3.5 扩散模型

#### 原理（DDPM）

DDPM（arXiv:2006.11239 [V]）定义一个逐步加噪的**前向过程**，再学习其逆过程：

$$q(x_n\mid x_{n-1})=\mathcal N\bigl(\sqrt{1-\beta_n}\,x_{n-1},\ \beta_n I\bigr),\qquad x_n=\sqrt{\bar\alpha_n}\,x_0+\sqrt{1-\bar\alpha_n}\,\epsilon,\ \ \bar\alpha_n=\prod_{i=1}^{n}(1-\beta_i),\ \epsilon\sim\mathcal N(0,I)$$

网络 $\epsilon_\theta$ 学习预测所加的噪声，训练目标是：

$$\mathcal L=\mathbb E_{n,x_0,\epsilon}\Bigl[\bigl\lVert\epsilon-\epsilon_\theta\bigl(x_n,n,\mathbf c\bigr)\bigr\rVert^2\Bigr]$$

采样时从 $x_N\sim\mathcal N(0,I)$ 出发逐步去噪：

$$x_{n-1}=\frac{1}{\sqrt{\alpha_n}}\Bigl(x_n-\frac{\beta_n}{\sqrt{1-\bar\alpha_n}}\,\epsilon_\theta(x_n,n,\mathbf c)\Bigr)+\sigma_n z,\qquad \alpha_n=1-\beta_n,\ z\sim\mathcal N(0,I)$$

$\mathbf c$ 是条件信息。Score-based SDE 的统一视角（arXiv:2011.13456 [V]）把加噪与去噪看作连续时间的随机微分方程。**代价**：采样需要迭代 $N$ 步（常为数十到上千步），比 GAN、流慢得多。

#### 时序中的代表方法

| 方法 | 做法 | 任务 |
|---|---|---|
| **TimeGrad**（arXiv:2101.12072 [V]） | **自回归**：每个时间步的多变量向量由一个**条件扩散**模型采样，条件是 RNN 隐状态 $h_{t-1}$：$p_\theta(\mathbf x^0_{t_0:T}\mid\cdot)=\prod_t p_\theta(\mathbf x_t^0\mid h_{t-1})$（依原文印象，细节待核实）。摘要称它优化数据似然的变分下界，推理时通过 Langevin 采样把白噪声变成目标分布的样本 | 多变量概率预测 |
| **CSDI**（arXiv:2107.03502 [V]） | **条件分数扩散**，显式为**填补**训练：把观测值拆成条件部分与待填补目标部分（自监督地构造训练任务），以观测值为条件去噪出缺失值；网络可利用观测值之间的相关性。摘要称在医疗与环境数据上，概率填补指标较已有方法改善 40–65%，确定性填补误差降低 5–20%，并可用于插值与概率预测 | 概率填补（兼预测） |
| **SSSD**（arXiv:2208.09399 [V]） | 条件扩散 + **结构化状态空间（S4）**作内部架构，擅长长程依赖；摘要强调在"blackout"整段缺失的困难场景下，此前方法给不出有意义的结果，而 SSSD 能达到或超过当时的最优水平 | 填补与预测 |
| **TSDiff**（arXiv:2307.11494 [V]） | **无条件**训练的扩散模型，靠**自引导**（self-guidance）在推理时条件化到下游任务，无需辅助网络或修改训练；用于预测（predict）、对基础预测器的预测做**精修**（refine）、**合成数据**（synthesize） | 预测、精修、合成 |
| **Diffusion-TS**（arXiv:2403.01742 [V]） | 编码器-解码器 Transformer 加**解耦的时间表示**（分解引导），训练时直接**重构样本**而非噪声，并结合傅里叶损失项；可无需改动扩展到预测与填补 | 无条件合成，兼条件任务 |
| 综述 | *Diffusion Models for Time Series Applications: A Survey*（arXiv:2305.00624 [V]） | 预测、填补、生成三类任务的系统梳理 |

#### 优缺点

| | |
|---|---|
| **优点** | 样本质量与多样性好；训练比 GAN 稳定；能表达多模态、复杂联合分布；一个模型可经引导服务多任务（TSDiff）；对整段缺失的填补尤为适用（SSSD） |
| **缺点** | **采样慢**（多步迭代）；训练与调参成本高；似然仅有下界；对短序列、小数据易过拟合；对预测校准需要单独检验 [经验] |
| **适用** | 需要复杂联合分布、多模态未来、概率填补、合成数据；对延迟不敏感的离线场景 |

### 3.6 流匹配与连续值生成

**流匹配**（flow matching）是扩散之后的一类训练范式：不逐步加噪，而是学一个**向量场** $v_\theta$，把噪声分布沿连续路径输运到数据分布。常用的条件流匹配形式（标准形式，细节以各论文为准，待核实）：

$$x_t=(1-t)\,x_0+t\,x_1,\ \ x_0\sim\mathcal N(0,I),\ x_1\sim p_{\text{data}},\qquad \mathcal L=\mathbb E_{t,x_0,x_1}\bigl\lVert v_\theta(x_t,t,\mathbf c)-(x_1-x_0)\bigr\rVert^2$$

采样时从噪声出发，对常微分方程 $\dot x=v_\theta(x,t)$ 积分，步数通常比扩散少。

**Sundial**（arXiv:2502.00816 [V]）把这一思想用于时序基础模型：预测**下一个 patch 的分布**，提出基于流匹配的 **TimeFlow Loss**，使 Transformer 能在**连续值**时间序列上原生预训练，无需离散 tokenization；条件于任意长度的序列，可**生成多条可能的预测**，并以 TimeFlow Loss 缓解模式坍塌。摘要同时称其使用 TimeBench（约一万亿个时间点）预训练，在点预测与概率预测基准上表现领先，并能在几毫秒内给出零样本预测。更详细的基础模型讨论见[基础模型篇](0608_ML_Tasks_TimeSeries_Foundation)。

| | |
|---|---|
| **优点** | 无需离散化；采样步数通常少于扩散；可输出多样的预测样本 |
| **缺点** | 较新，独立验证有限；训练目标与路径设计影响大 [经验] |

### 3.7 生成式异常检测

思路：模型学到"正常数据的分布"，**偏离分布或难以被重构**的点即为异常。

| 做法 | 异常分数 |
|---|---|
| 重构（VAE、扩散去噪后重构） | $\lVert x-\hat x\rVert^2$ |
| 密度（流、似然） | $-\log p(x)$ |
| 预测分布的偏离 | 真实值在预测分布中的分位位置、负对数似然 |

[经验] 生成式异常检测的优势是**对复杂正常模式的刻画**，风险与其他深度异常检测相同：评估协议（point-adjust）与基线问题（见 [metrics §3.3](0610_ML_Tasks_TimeSeries_Metrics)、[深度篇 §3.7](0606_ML_Tasks_TimeSeries_Deep)、[机器学习篇 §3.6](0605_ML_Tasks_TimeSeries_ML)）。Audibert et al.（arXiv:2204.01637 [V]）的结论提示：不能默认生成式或深度方法优于传统方法。

### 3.8 合成数据：用途与评估

| 用途 | 说明 |
|---|---|
| **数据增广** | 为罕见事件（故障、极端天气）补充样本 |
| **隐私共享** | 用合成数据代替敏感原始数据（需单独评估泄漏风险，本文不展开） |
| **压力测试与模拟** | 生成多种可能的未来场景用于决策仿真 |
| **预训练数据** | 为基础模型补充多样性（见[基础模型篇](0608_ML_Tasks_TimeSeries_Foundation)） |

评估见 §1.4。TSDiff 的摘要报告：**用 TSDiff 合成的样本训练的下游预测器**，表现可超过在其他合成数据上训练的预测器（具体比较对象以原文为准）[V]。**重要提醒**：合成数据看起来逼真，不等于对下游任务有用，要用 TSTR 一类"可用性"指标验证 [经验]。

## 4. 方法总览对比

| 方法族 | 代表 | 联合分布 | 采样速度 | 训练稳定性 | 似然 | 典型用途 | 典型局限 |
|---|---|---|---|---|---|---|---|
| 参数化分布 | DeepAR | 需额外结构 | 快（自回归逐步） | 稳 | 显式 | 业务概率预测 | 分布族受限 |
| 分位数 / IQN | IQN | 边缘分位数 | 快 | 稳 | 无（pinball/CRPS） | 区间预测 | 路径依赖弱 |
| VAE | TimeVAE、GP-VAE | 潜变量 | 快 | 稳 | 下界 | 合成、填补 | 样本偏平滑 |
| GAN | TimeGAN | 隐式 | 快 | **差** | 无 | 合成 | 模式坍塌、评估难 |
| 归一化流 | 条件流预测 | 精确 | 快 | 中 | **精确** | 高维联合预测 | 结构受限 |
| 扩散 | TimeGrad、CSDI、SSSD、TSDiff、Diffusion-TS | 灵活 | **慢** | 较稳 | 下界 | 预测、填补、合成 | 采样慢 |
| 流匹配 | Sundial | 灵活 | 较快 | 中 | 无显式 | 基础模型的概率输出 | 较新 |

## 5. 发展趋势

下面各条分"事实"（基于上述已核对文献）与"判断"（编者 [经验]，需持续观察）。

### 5.1 从"专用条件模型"到"无条件预训练 + 引导"

- **事实**：TimeGrad、CSDI 是为特定任务训练的条件模型；TSDiff（[V]）训练**无条件**扩散模型，靠自引导服务预测、精修、合成；Timer（[V]）把预测、填补、异常检测统一为生成任务。
- **判断**：一个生成模型服务多任务，是向[基础模型](0608_ML_Tasks_TimeSeries_Foundation)靠拢的方向 [经验]。

### 5.2 从扩散到更快的连续生成

- **事实**：扩散采样需迭代多步；Sundial（[V]）用流匹配训练连续值生成，摘要称零样本预测可在几毫秒内完成。
- **判断**：**采样速度**会成为生成式预测能否落地的关键，流匹配与蒸馏类加速值得关注 [经验]。

### 5.3 与结构化骨干结合

- **事实**：SSSD（[V]）把扩散与 S4 结合；Diffusion-TS（[V]）把分解与傅里叶损失引入扩散。
- **判断**：生成模型的骨干与[深度篇](0606_ML_Tasks_TimeSeries_Deep)中的架构趋势同步（状态空间、分解、patch）[经验]。

### 5.4 概率预测的评估与校准

- **事实**：概率预测以 CRPS 与校准评估（[metrics §2](0610_ML_Tasks_TimeSeries_Metrics)）；共形预测为任意模型提供覆盖保证（[经典篇 §3.15](0604_ML_Tasks_TimeSeries_Classical)）。
- **判断**：**生成式模型 + 共形校准**是合理组合：生成模型提供形状，共形外壳保证覆盖 [经验]。

### 5.5 合成数据评估仍无统一标准

- **事实**：TimeVAE、Diffusion-TS 等论文各自采用相似性与可用性评估（[V] 摘要）；扩散综述（[V]）指出现有方法的共同局限。
- **判断**：合成数据的评估规范化是开放问题；在没有统一标准前，应以**下游任务的可用性**为主 [经验]。

## 6. 实践建议 [经验]

**什么时候需要生成式**

| 需求 | 建议 |
|---|---|
| 只要几个分位数/区间 | **分位数回归**（GBDT、TFT）或"点预测 + 共形"，成本低、稳 |
| 需要路径级依赖（累计需求、峰值时刻） | 自回归采样（DeepAR）、扩散或流 |
| 整段缺失（blackout）填补 | CSDI、SSSD |
| 合成数据 / 增广 | TimeVAE（快速基线）、Diffusion-TS、TSDiff；用 TSTR 验证 |
| 需要精确似然 | 归一化流、参数化分布 |
| 对延迟敏感 | 避免多步扩散；用参数化分布、流或流匹配 |

**推荐流程**

1. 先做分位数基线（[机器学习篇 §3.3](0605_ML_Tasks_TimeSeries_ML)）和 DeepAR 一类参数化分布基线；
2. 只有基线的**边缘分位数不足以满足决策**，或需要路径级样本时，再试扩散/流；
3. 固定样本数 $S$，报告 CRPS 与**覆盖率**；
4. 用共形外壳校准最终区间（[经典篇 §3.15](0604_ML_Tasks_TimeSeries_Classical)）；
5. 合成数据用 TSTR 验证可用性。

**常见错误**

- 把"样本逼真"当成"分布校准"；
- 比较 CRPS 时样本数不一致；
- 对整段缺失只在随机缺失上评估；
- 用合成数据训练后在合成数据上评估，没有真实数据验证；
- 忽略扩散的采样成本，导致线上延迟不可接受。

**工具**（版本与接口以官方文档为准，待核实）

| 用途 | 库 |
|---|---|
| 概率预测 | GluonTS（arXiv:1906.05264 [V]）、PyTorch Forecasting |
| 扩散类 | 各论文开源实现（如 CSDI 的 GitHub 仓库，摘要给出） |

## 7. 生成式路线的局限

- **采样成本高**（扩散）；
- **训练与调参复杂**，对小数据易过拟合；
- **评估不统一**：合成数据的好坏缺乏标准；
- **校准需要单独检验**：生成得逼真不等于区间可信；
- **边际收益不确定**：许多业务用分位数加共形即可满足；
- **新方法的独立验证有限**：Sundial 等较新，需更多第三方评测。
