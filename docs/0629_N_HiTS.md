# N-HiTS

N-HiTS（Neural Hierarchical Interpolation for Time Series Forecasting）是 Challu、Olivares、Oreshkin 等人提出的长期（long-horizon）时间序列预测模型，论文 arXiv:2201.12886，PDF 版权页标注为 AAAI 2023。它是 N-BEATS 的后续工作：保留 N-BEATS 的"全连接块 + 双重残差（backcast / forecast）"骨架，在每个块前加入**多速率输入池化**（multi-rate signal sampling，MaxPool），在每个块的输出端加入**层级插值**（hierarchical interpolation，MLP 只输出少量系数，再插值回完整 horizon）。

**一句话概括**：让不同的块各自负责一个频段——低频块看被强烈池化的输入、输出很少的系数再插值成长曲线；高频块看更细的输入、输出更多系数——最后把所有块的预测相加，既降低长 horizon 的计算量，也让预测更平滑、更可解释。

本文在时间序列专题中的位置见 [时间序列总览](/0603_ML_Tasks_TimeSeries) 与 [深度学习方法](/0606_ML_Tasks_TimeSeries_Deep)；相邻方法参见 [DeepAR](/0625_ML_Tasks_TimeSeries_Deep_DeepAR)、[TCN](/0626_ML_Tasks_TimeSeries_Deep_TCN)。N-BEATS 为同批文章，此处只引用名字。

> 标注约定：未标注的内容来自论文；`[解读]` 为作者对论文的理解，`[经验]` 为一般经验判断，`[待核实]` 为论文之外且未能核实的信息。

## 1. 解决什么问题

### 1.1 长 horizon 预测的两个痛点

论文开头指出，神经网络做长期预测很难，因为模型"无界的表达能力"会直接转化成过高的计算复杂度和**预测波动（volatility）**，两者在长 horizon 下尤为严重：

- 论文称注意力层与全连接层的内存和计算都随预测长度 `H` 呈**二次**增长。
- 论文 Fig. 1 用 Electricity 数据集上的高容量全连接模型（N-BEATSi）展示：随 horizon 增大，计算时间、参数量和 MAE 都明显恶化；论文称基于注意力的模型有类似现象。

当时（2022 年初）长期预测的主流是各种 Transformer 变体（Informer、Autoformer、FEDformer、Reformer、LogTrans），研究重点多放在"让 attention 更稀疏/更快"。N-HiTS 走另一条路：不改 attention，而是改**输入如何被采样**和**输出如何被合成**。

### 1.2 N-BEATS 的不足（论文视角）

论文指出，多数多步预测模型的网络输出基数等于 horizon `H`，例如 N-BEATSi 中 `|θ^f| = H`。`H` 越长，输出层越大，参数和计算随之膨胀，带来"不必要的表达能力爆炸"。同时，各块都在同一个时间分辨率上输出，没有被约束去分工。N-HiTS 的改动就针对这两点。

## 2. 核心思想与结构

### 2.1 整体框架

N-HiTS 由 `S` 个 stack 组成，每个 stack 有 `B` 个 block；每个 block 是一个带 ReLU 的 MLP。网络输入是目标序列自身的 `L` 个滞后值 `y_{t-L:t}`。

```
Model input y_{t-L:t}
   |
   v
+- Stack 1 -------------------------------+   forecast_1 --+
|  Block: MaxPool(k1) -> MLP -> θf, θb    |                |
|         θf -- interpolate --> ŷ         |                |
|         θb -- interpolate --> ỹ (backcast)               |
|  residual: x <- x - ỹ                   |                |
+-----------------------------------------+                |
   | residual input                                        v
   v                                                      sum --> ŷ_{t+1:t+H}
+- Stack 2 (k 更小, r 更大) ... ----------+   forecast_2 --+
   v
  ...  Stack S (最小的 k, 最大的 r) ------->  forecast_S --+
```

与 N-BEATS 一致的部分（论文原文）：

- 每个块的 MLP 学习 backcast 与 forecast 两组基系数；
- backcast 用于"清理"后续块的输入，forecast 相加得到最终预测（doubly residual stacking）；
- 块被分组为 stack，每个 stack 学习数据的某种特性。

### 2.2 Multi-Rate Signal Sampling（多速率输入采样）

在第 `ℓ` 个块的输入端先做一次 MaxPool，核大小为 `k_ℓ`：

```
y^(p)_{t-L:t,ℓ} = MaxPool(y_{t-L:t,ℓ}, k_ℓ)          (论文 Eq.1)
```

- `k_ℓ` 越大，越多高频/小时间尺度成分被截掉，该块被迫关注大尺度、低频内容，利于产生一致的长期预测。
- 论文强调这也减少了大多数块的 MLP 输入宽度，降低内存、计算与参数量（缓解过拟合），同时"保持原有的感受野（receptive field）"。
- 论文把它称为 multi-rate：每个块的 MLP 面对的"有效采样率"不同。相关的经典做法是混频采样回归 MIDAS（论文 Related Work 提及）。

**小例子（论文附录 G Fig. 2 的数字）**：输入序列 `[2, 5, 8, 5, 2, 5, 6, 2, 10, 6, 9, 3]`，每 3 个点一组（相当于 `k=3`）：MaxPool 得到 `[8, 5, 10, 9]`，AveragePool 得到 `[5, 4, 6, 6]`（图中取整显示）。12 个点压成 4 个，MaxPool 保留每组的峰值，AveragePool 则把峰值抹平。（数值已对照渲染图核对；`[解读]` 这里窗口等于 stride，论文正文未明确写 stride。）

小例子 2 `[解读]`（自己的算术，非论文数字）：取 Table A3 的 `m=5`、`H=720`，则 `L=3600`。池化核 `[k1,k2,k3]=[8,4,1]` 时，三个块的 MLP 输入宽度分别约为 `450 / 900 / 3600`。仅看第一层线性层（忽略 bias），`N_h=512` 时权重数约为 `512×450=230,400`、`512×900=460,800`、`512×3600=1,843,200`；若三块都不池化（即 N-HiTS4 / N-BEATSg 的做法）则都是 `1,843,200`。每个块仍然能"看到"全部 3600 步历史，只是分辨率不同。

池化为什么对"长期预测"有用 `[解读]`：长 horizon 主要由慢变化的成分（趋势、长周期）决定，高频细节对远期几乎没有预测力，MaxPool 先把它们压掉，既省参数，也减少模型去拟合噪声的机会。选 MaxPool 而非 AveragePool 的经验依据只有附录 G 的比较（见 §4.4）。

### 2.3 非线性回归

池化之后，块用 MLP 得到隐向量 `h_ℓ ∈ R^{N_h}`，再用两个线性层分别投影出前向（forecast）和后向（backcast）系数：

```
h_ℓ  = MLP(y^(p)_{t-L:t,ℓ})
θf_ℓ = LINEAR_f(h_ℓ)
θb_ℓ = LINEAR_b(h_ℓ)                                 (论文 Eq.2)
```

### 2.4 Hierarchical Interpolation（层级插值）

关键点：`θf` 的维度不再等于 `H`，而是

```
|θf_ℓ| = r_ℓ · H        （r_ℓ 为 expressiveness ratio，表达率）
```

即"每单位输出时间对应多少个参数"。再用插值函数 `g` 把系数还原到原始采样率：

```
ŷ_{τ,ℓ} = g(τ, θf_ℓ),  τ ∈ {t+1, ..., t+H}
ỹ_{τ,ℓ} = g(τ, θb_ℓ),  τ ∈ {t-L, ..., t}            (论文 Eq.3)
```

插值可以是最近邻、分段线性或三次（C0 / C1 / C2，论文附录 G 比较）。论文展示的线性插值：时间划分 `T = {t+1, t+1+1/r, ..., t+H-1/r, t+H}`，在相邻两个结点 `t1`、`t2 = t1 + 1/r` 之间做线性插值（论文 Eq.4）。可以把 `θf` 看成"时间轴上每隔 `1/r` 步放一个结点的取值"。

**层级**体现在 `k` 与 `r` 的同步安排：

- 靠近输入的块：`k` 大（输入被强烈池化）、`r` 小（输出系数少、插值更"激进"），产生低分辨率、低频的预测成分；
- 靠近输出的块：`k` 小、`r` 大，补充细粒度的高频/间歇成分。
- 论文建议使用**指数递增**的 expressiveness ratio，以较少的参数覆盖较宽的频段；或让每个 stack 对应一个已知周期（如周、日），用匹配的 `r`。

最终预测与残差：

```
ŷ_{t+1:t+H} = Σ_ℓ ŷ_{t+1:t+H, ℓ}
y_{t-L:t, ℓ+1} = y_{t-L:t, ℓ} - ỹ_{t-L:t, ℓ}
```

这样前面的块先把低频成分合成并从输入中扣除，后面的块专注于其余部分。论文消融（附录 G）称：**"先合成并去掉低频/大尺度成分，再细化高频"的顺序对结果影响显著，是最佳配置**。

### 2.4.1 输出头维度与参数量：一个带数字的例子

取 `H=720`、`N_h=512`、`1/r=[24,12,1]`（Table A3 的候选之一，`S=3`、`B=1`）：

-- | -- | -- | --
Block 1 | `720/24 = 30` | `512×30 = 15,360` | 每 24 步一个结点，线性插值
Block 2 | `720/12 = 60` | `512×60 = 30,720` | 每 12 步一个结点
Block 3 | `720/1 = 720` | `512×720 = 368,640` | 每步一个值，无插值
合计 | | `414,720` | 
对照：N-BEATSg 风格（每块都输出 720 维） | `720×3` | `3×368,640 = 1,105,920` | 无

（`[解读]` 上表是用论文公式 `|θf|=rH` 和 Table A3 的超参做的算术，论文未给出这张表；backcast 头同理，它的长度由输入长度 `L` 决定而非 `H`。）

线性插值的算术小例子 `[解读]`：若相邻两个结点 `t1`、`t2=t1+4`，系数分别为 `θ[t1]=2.0`、`θ[t2]=6.0`，则按论文 Eq.4，`τ=t1+1` 处的值为 `2.0 + (6.0-2.0)/4 × 1 = 3.0`，`τ=t1+2` 处为 `4.0`。也就是说，低频块只学少数"拐点"，其余点由直线连出，所以输出天然平滑；论文 Fig. 5(a) 中 Stack 1 的分量就是只有几个结点的折线。

附录 G 给出的另外两种插值 g：最近邻 `ŷ_τ = θ[t*]`，`t* = argmin |t-τ|`；三次 Hermite 插值用两端结点的取值和一阶导数（基函数如 `φ1(τ)=2τ³-3τ²+1`）。论文最终采用线性。

### 2.4.2 与 N-BEATS 的逐点区别

项 | N-BEATS | N-HiTS
-- | -- | --
块输入 | 完整的 `L` 维输入（或残差） | 先 MaxPool 到更短，`k_ℓ` 随块不同
forecast 头维度 | `H`（`|θf|=H`） | `r_ℓ·H`，靠近输入的块更小
时间分辨率 | 各块相同 | 各块不同，由 `k`、`r` 协同
如何合成输出 | 直接输出（或乘固定基，如 N-BEATSi 的多项式/正弦） | 插值函数 `g` 还原到完整 horizon
块间分工 | 靠 backcast 残差隐式分工 | 残差 + 池化 + 插值共同诱导按频段分工
长 horizon 复杂度（论文 Table A2） | N-BEATSg `O(HB)`，N-BEATSi `O(H²B)` | `O(H(1-r^B)/(1-r))`
共同点 | MLP 块、doubly residual stacking、全局单变量模型、直接多步预测 | 同左

### 2.5 为什么有效：效率与理论

**复杂度**（论文附录 B 与 Table A2，设 `L = O(H)`，已对照渲染页核对）：块内由全连接层主导，复杂度 `O(H·N_h)`（`N_h` 视为常数）。N-BEATSg 的时间/内存为 `O(HB)`，N-BEATSi 为 `O(H²B)`；N-HiTS 取 `r_ℓ = r^ℓ`（指数递增的表达率）时，空间复杂度为几何级数 `O(Σ_{ℓ=0}^{B} H·r^ℓ) = O(H(1-r^B)/(1-r))`，Table A2 中时间复杂度也是同一形式。Table A2 同时列出 Transformer `O(H²)`、Informer/Autoformer `O(H log H)` 等对照。`[解读]` 该式在 `r<1` 时随 `H` 线性、随 `B` 收敛；这是渐近式，实际用的是 Table A3 的离散候选。

**理论**（论文 Neural Basis Approximation Theorem，附录 A）：若预测映射在 `L²([0,1])` 中、多分辨率函数族 `V_w`（分段常数/分段线性/样条）可任意逼近 `L²`，且投影系数随输入光滑变化（如 K-Lipschitz），则有限个多分辨率系数的神经网络可以任意逼近"无限/稠密 horizon"的预测函数。附录证明了分段常数（Haar）情形，称线性、样条情形类似。`[解读]` 这是一个存在性（逼近）结论，并不保证训练能找到最优解，也不直接解释为什么经验精度更好。

论文在讨论部分还提到：层级插值可从**多分辨率分析/小波**角度理解，用小波诱导的空间替换插值函数是后续研究方向；这是论文自己提出的展望，不是已做的实验。

### 2.6 可解释的分解

与 N-BEATSi 用固定多项式（趋势）+ 正弦（季节）基不同，N-HiTS 的基是"局部定义的插值核"，系数沿 horizon 局部决定，因此论文称它能重构非周期/非平稳信号，超越固定的 Fourier 投影（Fig. 3）。论文 Fig. 5 在 ETTm2、预测 720 步的例子中：(a) 完整模型的 Stack 1 分量是只有几个结点的平滑折线（趋势），Stack 2 呈明显周期波动（季节），Stack 3 接近 0；(b) 去掉层级插值与多速率采样后，三个 stack 的分量都类似噪声、无法解释。`[解读]` 这是定性展示，且来自单个例子。

## 3. 训练与推理

### 3.1 预测策略与模型性质

- **多步直接预测（joint / multi-step）**：一次前向传播输出整个 `H`，避免递归预测的误差累积。
- **单变量模型**：多变量数据集上，每个变量只用自己的历史预测，指标在变量间平均；同一数据集内所有序列共享参数（global model）。论文据此提出疑问：多变量 Transformer 类模型被一个单变量模型明显超过，说明它们要么在边缘分布层面过拟合，要么没能有效利用多变量信息。这是论文的讨论，不是严格验证的结论。
- **只用目标序列历史**：模型输入只含目标序列自身滞后值，论文方法部分没有外生变量/协变量。

### 3.2 训练设置（论文 Section 4 与附录 D）

### 3.3 推理

推理时对每条序列取最近 `L` 步，前向通过各 stack，累加 forecast，一次得到 `H` 步预测；多变量数据逐变量独立预测。评估采用滚动窗口（rolling windows）。

## 4. 实验与结论

### 4.1 设置

沿用 Informer / Autoformer 的实验设置。论文共使用 6 个数据集：ETTm2（15 分钟，7 个序列）、Exchange（日度，8 个序列）、ECL（电力，小时聚合，321 个客户）、TrafficL（小时，862 个传感器）、Weather（10 分钟，21 个气象指标）、ILI（周度，7 个序列）。horizon：除 ILI 外为 `{96, 192, 336, 720}`，ILI 为 `{24, 36, 48, 60}`。每个数据集用训练集的均值与标准差归一化；划分为 70% / 10% / 20%（训练/验证/测试），ETTm2 的验证集为 20%（论文原文如此）。指标 MAE 与 MSE，结果为 8 次运行平均。

Table 1 中 N-HiTS 在多数格子上最优（加粗），但 ECL、TrafficL 的若干列被 N-BEATS 或 FEDformer 超过。基线：多变量方向有 FEDformer、Autoformer、Informer、Reformer、LogTrans；另有单变量基线 DilRNN、auto-ARIMA；表中还包含 N-BEATS。

### 4.2 主要结果

论文文字结论：

- 相对最佳基线，跨数据集与 horizon 平均，MAE 降低 14%，MSE 降低 16%；最短 horizon（96/24）与其他 SOTA 相当，最长 horizon（720/60）MAE 降低 11%、MSE 降低 17%。
- 摘要则写"相对最新 Transformer 平均精度提升接近 20%，计算时间降低一个数量级（50 倍）"；正文效率部分写"比 Autoformer 快 45 倍"。`[解读]` 摘要、引言（16%）、正文（14%/16%）的数字口径略有不同，引用时建议以正文 Table 1 与文字为准，并注明来源。

读表要点：

- 并非处处第一：ECL/96 与 TrafficL/96 上 N-BEATS 略优，ECL/720 的 MSE 上 FEDformer 略优（0.231 vs 0.243）。论文也承认在最短 horizon 上与最佳方法"可比"。
- 长 horizon 的优势较大，例如 Exchange/720 的 MSE 0.798 对 FEDformer 的 1.090。
- 论文附录 E：8 次运行的标准差平均约占 MSE 的 2.9%、MAE 的 1.75%；Exchange 的运行间方差最大。
- 附录 E 还与同期未经同行评审的 ETSformer、Preformer 比较，称 N-HiTS 对次优方法仍有 MAE 11%、MSE 9% 的提升，仅短 horizon 的 Exchange 上 ETSformer 更好；论文自己标注了这些对比的 caveats（未同行评审、horizon 设置不完全一致、多数只报单次运行）。
- 附录 F 单变量实验（ETTm2、Exchange）：相对最佳替代方法 MAE 降低 17%、MSE 降低 25%；基线包括 Autoformer、Informer、LogTrans、Reformer、N-BEATS、DeepAR、Prophet、auto-ARIMA。

### 4.3 计算效率

论文在 ETTm2 上监控整个训练过程（Fig. 4）：

- 相比 Autoformer，训练快 45 倍；
- 参数量不到次优方案的 26%（论文解释为随输入长度线性增长）；
- 相比原版 N-BEATS，快 1.26 倍，参数量仅 54%；
- 论文称（附录 I）与 N-BEATS 类似，参数量/训练复杂度不随数据集规模增长（全局共享参数）。

### 4.4 消融

论文 Table 2（5 个数据集、8 次运行平均）比较：N-HiTS（两者都有）、N-HiTS2（仅层级插值）、N-HiTS3（仅多速率采样）、N-HiTS4（两者都无，对应 N-BEATSg）、N-BEATSi。以 horizon 720 的平均误差为例：

模型 | MSE@720 | MAE@720
-- | -- | --
N-HiTS | 0.484 | 0.439
N-HiTS2（仅插值） | 0.498 | 0.450
N-HiTS3（仅池化） | 0.518 | 0.454
N-HiTS4（无，≈N-BEATSg） | 0.548 | 0.468
N-BEATSi | 0.794 | 0.597

（已对照渲染页核对；Table 2 中 N-HiTS 在 720 上两项指标均为最优，96 上 MSE 为 N-HiTS3 最优、N-HiTS 次优。）两个组件互补，组合最好；但在 horizon 96 上差别很小，个别指标上 N-HiTS3 甚至略好（MSE 0.192 vs 0.195）。论文还指出 N-BEATSi 的多项式/正弦基对长 horizon 是"有害的归纳偏置"。

其他附录消融（附录 G 的这些实验在 ETTm2、Exchange、ECL、TrafficL、Weather 五个数据集的**验证集**上进行，每次只改变一个因素）：MaxPool 优于 AveragePool（Table A6：多数数据集和 horizon 上 MaxPool 的 MSE/MAE 更低，也有个别例外）；线性与三次插值都稳定优于最近邻（最多约 15.8% 与 7.0%），线性与三次之间论文称"结果不确定"，只是平均而言线性在精度和计算上略占优，所以主实验用线性（正文概括为"线性优于最近邻与三次"，附录文字更保守）；层级顺序（先低频后高频）很重要；把这两项技术加到 DilRNN 上（附录 H）：主要提升来自层级插值，多速率采样对 DilRNN 帮助不大（论文猜测与 RNN 只汇总历史有关），两者组合与只用插值差别很小。论文据此认为层级插值不限于 N-HiTS 架构。

## 5. 优缺点与局限

### 5.1 论文自述

- 优势：长 horizon 精度与效率兼顾；预测可分解、可解释；层级插值可迁移到其他架构（如 DilRNN，附录 H；多速率采样在 DilRNN 上收益不明显）。
- 论文自述的局限/开放问题：
  - 模型是单变量的，不使用其他变量的信息；论文将"如何有效融合多变量信息"留作后续方向；
  - 论文称自己"只触及了表面"，更先进的多尺度处理仍有空间；
  - 与同期工作的对比有 caveats（见 §4.2）。

### 5.2 `[经验]` / `[解读]`

- `[解读]` 论文评估的是固定数据集上的点预测（MAE/MSE），没有概率预测、分层一致性或协变量实验；因此不能直接说 N-HiTS 适合需要预测区间或丰富协变量的场景。
- `[经验]` 池化核和 `r` 的选择本质上编码了"数据有哪些时间尺度"的先验；周期结构不明显或尺度很杂的序列，可能需要更多调参。
- `[经验]` 后来关于线性模型（如 DLinear）与 PatchTST 的工作表明，长期预测基准上简单模型可以很强；N-HiTS 的结果应放在该背景下对比，不宜孤立解读。具体对比数字本文未核对，`[待核实]`。

## 6. 与相关方法对比

方法 | 输入处理 | 输出合成 | 分解/可解释 | 备注
-- | -- | -- | -- | --
N-BEATSg（generic） | 全长输入，无池化 | 每块输出 `H` 维 | 无约束 | N-HiTS 的前身
N-BEATSi（interpretable） | 同上 | 多项式 + 正弦基 | 固定趋势/季节基 | 论文称对长 horizon 归纳偏置不利
N-HiTS | MaxPool 多速率 | `rH` 维系数 + 插值，逐块求和 | 各块对应频段 | 单变量、全局模型
Informer / Autoformer / FEDformer | encoder 注意力（稀疏/自相关/频域） | decoder 多步输出 | Autoformer 等含序列分解 | 多变量
[DeepAR](/0625_ML_Tasks_TimeSeries_Deep_DeepAR) | 自回归 RNN | 逐步采样，概率输出 | 无 | 概率预测，递归式
[TCN](/0626_ML_Tasks_TimeSeries_Deep_TCN) | 因果膨胀卷积 | 视设计而定 | 无 | 以卷积获得大感受野

`[解读]` 池化与膨胀卷积、小波分解有相通之处：都是用多尺度视角扩大感受野或分离频段。N-HiTS 的特点是在输出端也做多尺度，并用 backcast 残差把"已解释的频段"从输入中扣除。

与综述 [时间序列总览](/0603_ML_Tasks_TimeSeries) 及 [深度学习方法](/0606_ML_Tasks_TimeSeries_Deep) 的说法（多速率输入池化 + 层级插值、不同块负责不同频率、降低长 horizon 计算量并改善精度）一致。

## 7. 使用方式

论文摘要给出的代码入口是 Nixtla 的 `neuralforecast` 库（`https://github.com/Nixtla/neuralforecast`），库中应有 N-HiTS 模型类。其具体类名与参数名本文未核对，请直接查阅该库官方文档，此处不给示意代码 `[待核实]`。把论文超参映射到库参数时，可参考下表：

论文超参 | 含义 | 论文取值
-- | -- | --
`m` | 输入长度 `L = m·H` | 5
`k_ℓ` | 各块 MaxPool 核 | 候选见 §3.2
`1/r_ℓ` | 各块每隔多少步一个结点 | 候选见 §3.2
`S`、`B` | stack 数、每 stack 块数 | 3、1
`N_h`、MLP 层数 | 隐藏宽度、层数 | 512、2
插值 `g` | 插值函数 | Linear

`[经验]` 实践要点：

- 先用论文 Table A3 的候选组合（如池化核 `[8,4,1]` / `[16,8,1]`）作为起点，再按数据的主周期调整 `1/r`；
- 输入长度取 horizon 的数倍，可与 DLinear、统计模型等做同口径对比；
- 如需多变量或协变量，需要查阅库中的扩展版本，论文原方法不包含。
