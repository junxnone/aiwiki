# TS2Vec

TS2Vec 出自论文 *TS2Vec: Towards Universal Representation of Time Series*（Zhihan Yue、Yujing Wang 等，北京大学与微软，AAAI 2022，arXiv:2106.10466）。它是一个无监督（自监督）的时间序列表示学习框架：**对每个时间戳学一个向量**，再用简单的聚合（max pooling）得到任意子序列、乃至整条序列的表示，分类、预测、异常检测都可以复用同一个编码器。

一句话概括：**TS2Vec = 时间戳掩码 + 随机裁剪构造两个"上下文视图"，同一时间戳在两个视图里的表示作为正样本；再用 max pooling 逐层缩短时间轴，在每一层都计算实例对比与时间对比损失。**

> 论文自称这是"first work that provides a flexible and universal representation method for all kinds of tasks"，这属于作者自述；本文只复述其做法与实验，不对"首个"做独立判断。

## 解决什么问题

论文指出已有无监督时间序列表示方法的三点不足：

- **粒度粗**：很多方法只学实例级表示（整段一个向量），适合聚类、分类；但预测和异常检测要推断某个时间戳或某段子序列的目标，整段的粗粒度表示不够。
- **缺少多尺度**：TNC 在固定长度的片段间做区分，T-Loss 随机取子序列作正样本，都没有在不同尺度上刻画序列以获得尺度不变的信息。
- **归纳偏置不一定成立**：CV/NLP 里常用的变换不变、裁剪不变，在时间序列上未必成立，因为序列的分布和语义会随时间变化，一段裁出来的子序列的分布可能与原序列明显不同。

论文给出的两个典型反例（论文 Figure 3）：

- **水平漂移（level shift）**：子序列一致性（subseries consistency，T-Loss 用）会把序列和它的子序列拉近，但子序列落在漂移前后两个水平上时，二者本来不该相似；
- **异常点**：时间一致性（temporal consistency，TNC 用）把相邻片段当正样本，异常点附近的相邻片段模式不同，却被当作相似，成了"假正样本"。

论文综述的第三种正样本选法是变换一致性（transformation consistency，TS-TCC 用）：对输入做缩放、置换等变换后要求表示不变。论文认为这三类做法都建立在对数据分布的较强假设上，不一定适合分布多变的时间序列。

## 整体结构

```
 输入 x_i (T x F)
     │  随机采两个重叠子序列 [a1,b1], [a2,b2]
     ├──────────────┐
  视图 1          视图 2           （各自独立采样一次时间戳掩码）
     │              │
 ┌───▼──────────────▼───┐
 │ 输入投影层 (FC)       │  z_{i,t} = W x_{i,t} + b
 │ 时间戳掩码 (潜向量上) │  被掩码的时间戳整个向量置 0
 │ 膨胀卷积 x10 残差块   │  每个时间戳得到 r_{i,t} ∈ R^K
 └───┬──────────────┬───┘
     r              r'          在重叠段 [a2,b1] 上逐时间戳对齐
     └──── 层次对比损失 ────┘
        每层: 时间对比 + 实例对比
        然后 max pool(k=2) 沿时间轴缩短一半，重复，直到长度为 1
```

编码器 $f$ 由三部分组成：

1. **输入投影层**：一个全连接层，把 $x_{i,t}\in\mathbb R^{F}$ 映射到更高维的潜向量 $z_{i,t}$；
2. **时间戳掩码**：在潜向量上按时间戳随机置零，生成增强的上下文视图；
3. **膨胀卷积模块**：10 个残差块，每块含两个 1-D 卷积，第 $l$ 块的膨胀系数为 $2^l$，感受野随深度指数增长。

输出为每个时间戳一个 $K$ 维向量：$r_i=\{r_{i,1},\dots,r_{i,T}\}$，$r_{i,t}\in\mathbb R^{K}$。

### 为什么掩码要加在投影层之后

论文的解释（附录 B.1）：时间序列的取值范围可能无界，没法给原始值找一个"特殊 token"；若用 0 来掩码原始输入，一段全为 0 的真实序列就和掩码无法区分。所以先做线性投影：

$$z_{i,t}=Wx_{i,t}+b,\qquad W\in\mathbb R^{F'\times F},\ b\in\mathbb R^{F'},\ F'>F$$

再把被掩码时间戳的 $z_{i,t}$ 置为 0。由于 $F'>F$，$W$ 的列空间不可能充满 $\mathbb R^{F'}$，存在一组参数 $b\notin\mathrm{span}(W)$，使得对任意输入 $x$ 都有 $Wx+b\ne 0$（论文 Lemma B.1），网络因此有能力区分"被掩码"和"未被掩码"。论文 Table 6 的对比：掩码放在投影层之后平均准确率 0.829，放在投影层之前 0.822，不使用时间戳掩码 0.820（128 个 UCR 数据集）。

## 核心思想：上下文一致性

对比学习的关键是怎么选正样本。TS2Vec 提出 **contextual consistency（上下文一致性）**：同一个时间戳，在两个不同增强上下文中的表示，互为正样本。上下文由两种操作生成，且**只在训练阶段使用**：

### 时间戳掩码（Timestamp Masking）

对一个样本的潜向量 $z_i=\{z_{i,t}\}$，沿时间轴乘一个二值掩码 $m\in\{0,1\}^{T}$，各元素独立地从 $p=0.5$ 的 Bernoulli 分布采样，每次前向都重新采样。这样同一个时间戳在两个视图里"周围可见的上下文"不同，网络必须靠剩下的上下文把它"认出来"。

### 随机裁剪（Random Cropping）

对 $x_i\in\mathbb R^{T\times F}$ 随机采两个重叠的片段 $[a_1,b_1]$、$[a_2,b_2]$，满足

$$0<a_1\le a_2\le b_1\le b_2\le T$$

在重叠段 $[a_2,b_1]$ 上，两个视图的表示应当一致。

论文在附录 B.2 里还给出了随机裁剪的另一个作用：避免**表示坍塌**。卷积层会隐式编码位置信息；若没有裁剪，两个视图的时间戳位置完全对齐，模型可以直接输出"位置的 one-hot"来最小化时间对比损失，只学到位置、不学内容。论文用两个指标 $\alpha$（表示与"纯位置表示"的相似度）和 $\beta$（不同样本表示之间的偏离）在 ScreenType 数据集上画训练曲线：去掉随机裁剪后 $\alpha$ 接近 1、$\beta$ 显著下降（Figure 8）。

两种操作的共同点，论文认为有两条好处：不改变序列的幅值（对时间序列很重要）；迫使每个时间戳在不同上下文中"重构自己"，增强鲁棒性。

## 层次对比损失

### 时间对比与实例对比

记 $i$ 为样本下标，$t$ 为时间戳，$r_{i,t}$ 与 $r'_{i,t}$ 是同一时间戳在两个视图里的表示，$\Omega$ 是两个子序列重叠部分的时间戳集合，$B$ 为 batch 大小。

**时间对比损失**：同一样本内，同一时间戳的两个视图为正样本，不同时间戳为负样本。

$$\ell_{temp}^{(i,t)}=-\log\frac{\exp(r_{i,t}\cdot r'_{i,t})}{\sum_{t'\in\Omega}\left(\exp(r_{i,t}\cdot r'_{i,t'})+\mathbb 1_{[t\ne t']}\exp(r_{i,t}\cdot r_{i,t'})\right)}$$

**实例对比损失**：同一时间戳上，同一样本的两个视图为正样本，batch 内其他样本在该时间戳的表示为负样本。

$$\ell_{inst}^{(i,t)}=-\log\frac{\exp(r_{i,t}\cdot r'_{i,t})}{\sum_{j=1}^{B}\left(\exp(r_{i,t}\cdot r'_{j,t})+\mathbb 1_{[i\ne j]}\exp(r_{i,t}\cdot r_{j,t})\right)}$$

两者合起来：

$$\mathcal L_{dual}=\frac1{NT}\sum_i\sum_t\left(\ell_{temp}^{(i,t)}+\ell_{inst}^{(i,t)}\right)$$

论文对二者分工的说明：以多用户用电数据为例，实例对比可能学到用户特有的特征，时间对比则挖掘随时间变化的动态趋势，二者互补。

[解读] 分母里分别带 $r'$ 与 $r$ 的两项，意味着负样本既取自另一视图、也取自同一视图。按分母逐项数：时间对比分母共 $2\lvert\Omega\rvert-1$ 项（含分子那一项正样本），即 $2\lvert\Omega\rvert-2$ 个负样本；实例对比分母共 $2B-1$ 项，即 $2B-2$ 个负样本。点积 $r\cdot r'$ 没有温度系数，论文公式里也没写。

### 沿时间轴逐层池化

仅在原始时间戳层面做对比，只能学到细粒度表示。TS2Vec 对 $r,r'$ 沿时间轴反复做 kernel size 为 2 的 max pooling，每一层都计算 $\mathcal L_{dual}$（论文 Algorithm 1），最后对层数取平均：

```
procedure HierLoss(r, r'):
    L_hier = L_dual(r, r');  d = 1
    while time_length(r) > 1:
        r  = maxpool1d(r,  kernel_size=2)
        r' = maxpool1d(r', kernel_size=2)
        L_hier = L_hier + L_dual(r, r');  d = d + 1
    return L_hier / d
```

$$\mathcal L_{hier}=\frac1d\sum_{k=0}^{d-1}\mathcal L_{dual}\bigl(r^{(k)},r'^{(k)}\bigr),\qquad r^{(k)}\ \text{为第}\ k\ \text{次池化后的表示}$$

自拟示意（非论文数据）：若重叠段长度为 8，各层的时间长度依次为 $8\to4\to2\to1$，共 $d=4$ 层，$\mathcal L_{hier}$ 是这 4 层 $\mathcal L_{dual}$ 的平均。越往上，一个位置覆盖的原始时间范围越大；到最顶层长度为 1，就只剩实例级对比。论文的说法是，最高语义层的对比使模型学到实例级表示。[解读] 最顶层时间轴上只有一个时间戳，$\ell_{temp}$ 的分子与分母相同，损失为 0，不提供梯度。

和相邻方法相比，论文的说法是：T-Loss 只在实例层面对比，TS-TCC 只在时间戳层面做实例对比，TNC 在某一个粒度上鼓励时间局部平滑，它们都不能同时覆盖多个粒度。

## 训练与推理

### 训练

- 无标签；训练时不知道下游任务，因此论文对所有任务固定同一组经验设定的超参，不做针对下游的超参优化（论文指出没有标签就难以用验证集做早停等选择）；每个任务只用训练集训练表示模型；
- batch size 默认 8，学习率 0.001，迭代次数：数据集大小小于 100,000 时为 200，否则 600；表示维度 $K=320$；
- 长序列训练时先裁成 3,000 个时间戳一段；输入投影层的隐藏通道数 64；膨胀卷积模块为 10 个 "GELU → DilatedConv → GELU → DilatedConv" 块（块间有 skip connection），卷积核大小 3，通道数 64，最后一个输出残差块把通道数映射到表示维度；
- 数据预处理：单变量用 z-score 归一化，多变量各变量独立 z-score；变长序列补 NaN，NaN 位置的掩码置 0（即当作缺失）；预测数据集额外加入分钟、小时、星期几、月内第几天、年内第几天、月份、年内第几周等时间特征（有时间戳时）；
- 论文发现 batch 大小（即负样本数）对单个数据集的结果有明显影响，但不同 batch size 的平均得分接近（附录 D.2）。

### 推理：从时间戳表示得到任意粒度表示

训练好的编码器直接前向（不再做掩码和裁剪），得到每个时间戳的 $r_t$。任意子序列的表示 = 对对应时间戳的表示做 max pooling。

## 下游任务怎么用

编码器只训练一次，下游用最简单的模型：

任务 | 用到的表示 | 下游模型（论文设置）
-- | -- | --
分类 | 整条序列所有时间戳 max pooling 得实例表示 | RBF 核 SVM（沿用 T-Loss 协议），惩罚系数 $C$ 在训练集上交叉验证、从 $\{10^i\}_{i=-4}^{4}\cup\{\infty\}$ 中网格搜索
预测 | 最后一个时间戳的表示 $r_t$ | 带 L2 惩罚的线性回归（ridge），直接输出未来 $H$ 步；多变量时输出维度为 $F\cdot H$；正则系数在验证集上从 $\{0.1,0.2,0.5,1,2,5,10,20,50,100,200,500,1000\}$ 里网格搜索
异常检测 | 最后一个时间戳在"掩码"与"不掩码"两次前向下的表示 | 无需额外训练，直接计算表示距离

### 异常检测的细节

论文采用流式评估：给定切片 $x_1,\dots,x_t$，判断最后一点 $x_t$ 是否异常。推理时前向两次：第一次只把最后一个观测 $x_t$ 掩码掉，第二次不掩码，两次得到的最后时间戳表示记为 $r_t^m$ 与 $r_t^u$，异常分数为 L1 距离：

$$\alpha_t=\lVert r_t^u-r_t^m\rVert_1$$

为避免漂移，用前 $Z$ 个点的局部均值做调整：

$$\bar\alpha_t=\frac1Z\sum_{i=t-Z}^{t-1}\alpha_i,\qquad \alpha_t^{adj}=\frac{\alpha_t-\bar\alpha_t}{\bar\alpha_t}$$

当 $\alpha_t^{adj}>\mu+\beta\sigma$ 时判为异常，$\mu,\sigma$ 为历史分数的均值和标准差，$\beta$ 是超参。论文两种设置都取 $\beta=4$（论文称 empirically）、$Z=21$（沿用 SR 论文）；正常设置里 $\mu,\sigma$ 用每条序列的训练部分计算，冷启动设置里用当前点之前的所有历史点计算。

论文的出发点有两点：一是异常点在学到的表示上可能与正常点有明显差异；二是 TS2Vec 鼓励同一时间戳在不同上下文下表示一致。[解读] 据此，正常点即使被掩码也能由上下文推出近似的表示，异常点则推不出来，所以两次表示差得远。这个解释是对论文思路的转述，论文没有对它做单独验证。

评估协议沿用 Ren et al. 2019 和 Xu et al. 2018：异常段内在容许延迟内（分钟级数据 7 步、小时级数据 3 步）检出任一点，则整段都算检出；预处理时对原始数据差分 $d$ 次（$d$ 由 ADF 检验确定的单位根数量决定）。

### 缺失数据鲁棒性

论文取 UCR 最大的 4 个数据集，对训练集和测试集随机遮掉一定比例的观测点。去掉层次对比或时间戳掩码时，准确率随缺失率上升迅速下降；完整 TS2Vec 在 50% 缺失时，UWaveGestureLibraryAll 上几乎没有变化，StarLightCurves、HandOutlines、MixedShapesRegularTrain 分别只下降 2.1%、2.1%、1.2%。

## 优缺点与局限

论文自述的优点：

- 一个编码器服务分类、预测、异常检测；表示可以聚合到任意粒度；
- 对缺失值鲁棒，训练时间短；
- 上下文一致性不引入变换不变、裁剪不变的假设。

论文没有单独的局限性章节，只在附录里提到：固定超参并非对每个数据集最优，改默认超参可能让部分数据集变好、另一些变差，batch size（负样本数）对单个数据集影响明显（附录 C.2、D.2）。

以下为本文的解读：

- [解读] 骨干对比和各项消融都只在 UCR 分类上做，论文没有在预测或异常检测任务上单独验证各组件是否同样重要。
- [解读] 预测只用最后一个时间戳的表示 $r_t$，信息要全压进一个 320 维向量里；预测的长度 $H$ 越长，线性头需要的表达力越大，论文实验里 $H$ 最大为 720（小时级）或 672（分钟级）。
- [解读] 论文的预测基线（Informer、LogTrans、LSTnet、TCN、N-BEATS）都是 2021 年及以前的方法；之后更强的预测模型（如 PatchTST）没有在论文里比较，此处不做数字上的结论。
- [解读] 论文的异常检测在流式协议下判断"最后一个点"，需要对每个点前向两次；是否适合大规模点级检测需要自己评估 [待核实]。

## 与相关方法对比

下表按论文 2.3、2.4 节与附录 A 的描述整理：

方法 | 正样本 | 对比发生的层级（论文说法）
-- | -- | --
T-Loss | 序列与其子序列（子序列一致性）；基于时间的负采样 + triplet loss | 只在实例层面
TNC | 相邻片段（时间一致性） | 在某一个粒度上鼓励时间局部平滑
TS-TCC | 同一样本的不同数据增强（变换一致性） | 只在时间戳层面做实例对比
TS2Vec | 同一时间戳在两个增强上下文中的表示 | 层次 max pooling，每层同时做实例对比和时间对比

[解读] 区别可以这样概括：前三者各自只在一个粒度上对比，并依赖子序列、时间邻近或数据增强这类先验；TS2Vec 用"同一时间戳、不同上下文"作为正样本，并把对比扩展到多个粒度。

与同系列相关：[TCN](/0626_ML_Tasks_TimeSeries_Deep_TCN) 的膨胀卷积思想在这里被用作编码器骨干（论文引用 Bai et al. 2018 说明膨胀卷积的大感受野）；总览见 [时间序列总览](/0603_ML_Tasks_TimeSeries)、[Deep 篇](/0606_ML_Tasks_TimeSeries_Deep) 与 [异常检测篇](/0609_ML_Tasks_TimeSeries_Anomaly)。
