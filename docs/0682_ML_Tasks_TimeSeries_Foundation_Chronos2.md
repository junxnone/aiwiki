# Chronos2

Chronos-2 出自论文 *Chronos-2: From Univariate to Universal Forecasting*（Abdul Fatir Ansari、Oleksandr Shchur、Jaris Küken、Andreas Auer 等，Amazon Web Services，arXiv:2510.15821）。它是一个预训练的时间序列基础模型，能以**零样本**方式处理**单变量、多变量以及带协变量**三类预测任务。核心机制是**组注意力（group attention）**：让同一"组"内的多条序列（可以是相关序列、多变量的各个变量，或预测目标与协变量）在每个块位置上共享信息，由此获得上下文学习（ICL）能力。多变量与协变量能力全部依赖合成数据训练获得。

**一句话概括：Chronos-2 是编码器式 Transformer（仿 T5 编码器），在每层里交替做沿时间轴的"时间注意力"和跨序列的"组注意力"；通过组 ID 与未来输入的设定，同一个模型无需改结构即可做单变量、多变量、协变量预测；输出 21 个分位数的直接多步预测。**

## 1. 解决什么问题

- 多数预训练预测模型（Chronos、TimesFM、Chronos-Bolt、TiRex 等）只支持**单变量**，遇到多变量就把各维当独立序列、并忽略协变量；
- 少数例外各有局限：Moirai-1 支持多变量但内部展平、难以扩展到高维；Toto 有跨变量注意力但不支持已知/类别协变量；COSMIC 利用协变量但目标仍限单变量；TabPFN-TS 能用已知协变量，但不能建模"仅过去协变量"或多变量目标；
- 实证上，这些方法相对单变量模型常只有微弱增益——**在零样本下联合建模多变量并有效使用协变量仍是难题**。

Chronos-2 用一个统一的组注意力机制来覆盖所有场景，无需结构改动或任务特定适配。

## 2. 问题定义

设历史序列 $Y_{1:T}=[y_1,\dots,y_T]$，每个 $y_t\in\mathbb R^{D}$（$D=1$ 为单变量，$D>1$ 为多变量），要预测未来 $H$ 步；协变量 $X_{1:T+H}=[x_1,\dots,x_{T+H}]$，$x_t\in\mathbb R^{M}$，可覆盖历史（$t\le T$）与未来（$t>T$）。概率预测的目标是估计：

$$
P\big(Y_{T+1:T+H}\mid Y_{1:T},\,X_{1:T+H}\big)
$$

其中：

- $T$：历史长度；$H$：预测长度；$D$：目标维数；$M$：协变量维数；
- 协变量（外生变量）分两类：**已知协变量**（未来值已知，如节假日、电价计划）与**仅过去协变量**（只有历史值）；
- 零样本指对从未见过的数据集不做任何训练、适配或微调直接预测。

## 3. 模型结构

### 3.1 整体流程

下图概括 Chronos-2 的推理管线。

```
目标 Y 与协变量 X
   │ 拼接：历史 V=[v_1..v_T]，未来 W=[w_{T+1}..w_{T+H}]
   │      （w 中，已知协变量填未来值，目标/仅过去协变量填"缺失"）
   │ 类别协变量 → 实数（单变量目标：目标编码；多变量：序号编码）
   ▼
稳健缩放：标准化 + sinh⁻¹ 变换
   ▼
每一列(每个维度)独立：加上元特征（时间索引 j、掩码 m）
   → 切成不重叠块(长度 P) → 残差网络嵌入 → 在上下文与未来之间插入 REG token
   ▼
Transformer 编码器：[时间注意力 → 组注意力] 交替堆叠
   ▼
分位数头：未来块嵌入 → 残差块 → 直接多步 21 个分位数 Ẑ ∈ R^{H×D×|Q|}
   ▼ 反归一化（逆 sinh⁻¹ 与标准化）
预测
```

图中：

- 输入构造把目标与协变量拼成统一矩阵，未来部分中未知的位置用缺失值表示，因此"缺失与否"自身就编码了任务设置；
- 每个维度（一列）被独立地分块与嵌入，序列间的信息交换完全交给组注意力；
- 时间注意力沿时间轴在同一序列的块之间聚合，组注意力在同一组的不同序列之间、同一块位置上聚合；
- 分位数头一次前向就生成多个目标块的预测，因此长预测不需要自回归启发式。

### 3.2 缩放与词元化

**稳健缩放**：对每个维度先标准化，再套 $\sinh^{-1}$ 变换，抑制异常值的影响：

$$
\tilde v_{t,d}=\sinh^{-1}\!\Big(\frac{v_{t,d}-\mu_d}{\sigma_d}\Big),\qquad \tilde w_{t,d}=\sinh^{-1}\!\Big(\frac{w_{t,d}-\mu_d}{\sigma_d}\Big)
$$

其中：

- $v_{t,d}$、$w_{t,d}$：历史与未来在第 $d$ 个维度、时刻 $t$ 的取值；
- $\mu_d$、$\sigma_d$：第 $d$ 维历史值 $[v_{1,d},\dots,v_{T,d}]$ 的均值与标准差，计算时排除缺失值；
- $\sinh^{-1}$：类对数的变换，进一步稳定方差、减小离群点对目标函数的影响（该变换在计量经济学与电价预测中用过）；
- 归一化后的 $\tilde V$、$\tilde W$ 拼成输入矩阵 $U=[\tilde V,\tilde W]\in\mathbb R^{(T+H)\times(D+M)}$。推理时对输出反向执行上述变换。

**元特征**：对 $U$ 的每一列额外附加两个特征：

- **时间索引** $j=-\frac{T}{C},-\frac{T-1}{C},\dots,0,\dots,\frac{H-1}{C}$：编码相对时间位置，其中 $C$ 是模型支持的最大上下文长度；对分块输入尤其有用；
- **掩码** $m_d$：取值 1 表示该位置有观测，0 表示缺失；它既标出历史中的缺失值，也标出哪些输入维度是未来已知协变量。

**分块与嵌入**：输入 $u_d$ 与元特征 $j,m_d$ 一起切成长度为 $P$ 的不重叠块（上下文与未来分别切块，不能整除时在上下文左侧或未来右侧补零）。第 $p$ 个块的 $u_p,j_p,m_p$ 拼接后经残差网络映射到模型维度：

$$
f^{in}_{\phi}:\ \mathbb R^{3P}\to\mathbb R^{D_{model}}
$$

其中：$\phi$ 是残差网络的参数；"3P"来自三段长度为 $P$ 的向量（值、时间索引、掩码）的拼接；$D_{model}$ 是 Transformer 的隐层维度。上下文块与未来块之间还插入一个特殊的 **REG token**，同时充当分隔符与注意力汇（attention sink）。

### 3.3 架构：时间注意力与组注意力

Chronos-2 是仿 T5 编码器的**仅编码器** Transformer，核心是两种注意力交替堆叠：

| 层 | 注意力沿哪个轴 | 位置编码 | 作用 |
| --- | --- | --- | --- |
| 时间注意力 | 时间轴：同一维度、不同块之间 | RoPE（替代 T5 的相对位置嵌入） | 捕获单条序列自身的时间依赖 |
| 组注意力 | 序列轴：同一块位置、同一组内的不同序列之间 | 无 | 在相关序列、变量或协变量之间交换信息，实现 ICL |

表中：

- 第一列是层的名称，第二列说明该层的注意力沿哪个维度聚合，第三列是位置编码，第四列是用途；
- 组注意力不用位置编码，因为组内的序列没有天然顺序；
- 批内可以同时存在多个大小不同的组，用长度为批大小 $B$ 的**组 ID** 向量 $g$ 标识；组注意力层把组 ID 转成二维注意力掩码，保证信息只在组内流动，不跨组。

"组"在不同任务里含义不同：

- **单条序列**：最小的分组，模型做单变量预测，不参考批内其他序列；
- **共享来源/元数据的一组序列**：联合预测（即少样本学习），在冷启动、历史短或下游数据分布与训练差异大时尤其有用；
- **共享动态的一组变量**：多变量预测，联合预测所有变量；
- **目标 + 仅过去协变量 + 已知协变量**：最通用的情形，预测目标时考虑协变量。

**分位数头**：经过交替的时间/组注意力层后，把目标维度的未来块嵌入送入残差块，一次生成多步分位数预测 $\hat Z\in\mathbb R^{H\times D\times|Q|}$。Chronos-2 预测 21 个分位数 $Q=\{0.01,0.05,0.1,\dots,0.9,0.95,0.99\}$（现有预训练模型常用 $\{0.1,\dots,0.9\}$ 九分位），其中极端分位数 0.01 与 0.99 提高了对罕见事件的覆盖，有助于异常检测与风险感知预测。

### 3.4 训练与推理

- **训练批次**混合三类任务：单变量预测、多变量预测（也涵盖仅过去协变量）、带已知协变量的多变量预测；每个任务分配唯一的组 ID，组 ID 与"未来输入 $W$ 是否已观测"两者结合，使模型可以推断出具体的预测设置；
- **损失**：对 21 个分位数的分位数损失（pinball loss）在所有预测步和批内样本上取平均，只对目标维度计算，已知协变量或缺失目标位置被排除；每个批次随机采样输出块数；
- **两阶段训练**：先用最大上下文 2048、较少输出块预训练；再把上下文扩展到 8192、增加最大输出块数——更长上下文有利于捕获高频序列的长季节性，多块输出使长预测不依赖启发式；
- **推理时靠组 ID 与未来输入指定任务**（论文 Table 2）：

| 任务 | 组 ID 设置 | 未来输入 $W$ |
| --- | --- | --- |
| 单变量预测 | 批内每条序列各有唯一组 ID，互相独立 | 全部缺失 |
| 多变量预测 | 同一多变量序列的各变量共享同一组 ID，不同序列组 ID 不同 | 全部缺失 |
| 协变量预测 | 同一任务的目标、仅过去协变量、已知协变量共享同一组 ID | 已知协变量填未来值，其余为缺失；协变量位置的预测被忽略 |
| 完全交叉学习 | 批内所有条目共享同一组 ID | 视各条目角色而定 |

表中：

- 第一列是任务类型，第二列是如何给批内序列分配组 ID，第三列是未来输入 $W$ 如何设置；
- "缺失"表示对应位置置为缺失值；"完全交叉学习"是论文在 5.1 节评测中使用的模式，让批内所有条目共享信息并联合预测；
- 要点：同一个模型、同一套权重，仅靠组 ID 与未来输入的设置切换任务。

## 4. 训练数据

对通用预训练模型而言，训练数据往往比结构更关键，而公开大规模数据主要是单变量。因此 Chronos-2 大量依赖**合成数据**：

- **真实数据**：选取 Chronos 与 GIFT-Eval 预训练语料中的部分数据集；
- **两类单变量合成生成器**：**TSI**（Trend、Seasonality、Irregularity，随机组合趋势/季节/不规则成分）与 **TCM**（Temporal Causal Model，从随机因果图出发自回归生成序列）；
- **多变量与协变量任务完全依赖合成数据**：通过"多变量化器（multivariatizer）"从基础单变量生成器（AR、ETS、TSI、KernelSynth）采样多条序列并施加依赖：
  - **同时刻（cotemporaneous）多变量化器**：在同一时间步对各序列做线性或非线性变换，引入瞬时相关；
  - **序列式（sequential）多变量化器**：引入跨时间的依赖，产生领先-滞后、协整等更丰富的性质；
  - 生成的多变量序列既用来构造多变量任务（预测所有变量），也用来构造协变量任务（随机指定一部分变量为已知协变量）。

## 5. 实验与结论

- **基准与对手**：fev-bench（强调多变量与协变量）、GIFT-Eval、Chronos Benchmark II；基础模型（1.2 亿参数）对比 TiRex、TimesFM-2.5、Toto-1.0、Moirai-2.0、TabPFN-TS、COSMIC、Sundial、Chronos-Bolt，以及 AutoARIMA/AutoETS/AutoTheta 与其集成；
- **总体**：三个基准上 Chronos-2 均达到 SOTA；在 fev-bench 上以较大幅度优于所有已有预训练模型；
- **ICL 收益拆分**：把 fev-bench 分成单变量子集（32 个任务）、多变量子集（26 个）、协变量子集（42 个），比较"开 ICL"与"单变量推理模式"（逐条独立预测并忽略协变量），论文发现 ICL 在各类任务上都带来增益，尤以协变量任务差距最大；
- **领域案例**：能源（16 个任务）与零售（17 个任务）中带动态协变量的任务上，Chronos-2 大幅优于最强的两个带协变量对手 TabPFN-TS 与 TiRex，且加入协变量对 Chronos-2 提升显著；
- **消融**：
  - 模型大小：28M 小模型在 GIFT-Eval 上的 skill score 仅比基础模型低约 1 个百分点，推理速度快近 2 倍，适合 CPU 与低资源环境；
  - 仅合成数据（Chronos-2-Synth）：在 Chronos Benchmark II 与 GIFT-Eval 上仅略逊于含真实数据的版本，在 fev-bench 上差距更大——说明合成数据极其重要；
  - 长上下文后训练：相比 2K 版本（Chronos-2-2K），尤其在含大量高频长季节性数据的 GIFT-Eval 上有提升。

## 6. 局限与展望

- 只支持数值与类别协变量；把文本等多模态输入纳入是未来方向；
- 组注意力的灵活性使得可以按稀疏元数据或稠密嵌入分组，做检索增强预测，缓解小样本/冷启动问题。

## 7. 总结 [解读]

- Chronos-2 的关键创新是"组注意力 + 组 ID/缺失掩码"这一统一接口，使单变量、多变量与协变量预测共用同一个预训练模型；
- 与 Chronos（量化 token + T5 语言模型式训练）相比，Chronos-2 改为直接输出 21 个分位数的多步预测，并面向多变量/协变量；与 TiRex（xLSTM、单变量）相比，Chronos-2 的优势主要体现在协变量任务；具体数值请以论文与榜单为准。
