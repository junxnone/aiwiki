# Sim2Real

Sim2Real（仿真到现实）：把在仿真中训练的策略迁移到真实机器人上，并缩小两者之间的差距（reality gap）。所属总览见 [RL Robot](https://github.com/junxnone/aiwiki/issues/458)，仿真见 [RL Robot Simulation](https://github.com/junxnone/aiwiki/issues/797)。

## 现实差距

```mermaid
flowchart LR
    S[仿真环境] -- 训练 --> P[策略 pi]
    P -- 部署 --> R[真实机器人]
    R -- 差距 --> G[性能下降]
    G -. 缩小差距 .-> S
```

图中：

- 策略在仿真里训练得很好，部署到真机却可能表现变差
- 虚线表示用各种方法反馈，使仿真更接近现实，或使策略对差异不敏感
- 关键结论：不是追求仿真绝对真实，而是让策略对真实世界的变化足够鲁棒

差距的主要来源：

| 来源 | 例子 |
| --- | --- |
| 动力学参数 | 质量、惯量、质心位置、摩擦、关节阻尼不准 |
| 执行器 | 电机带宽、延迟、力矩限幅、减速器间隙、非线性 |
| 接触 | 接触刚度、阻尼、摩擦模型与真实不一致 |
| 感知 | 传感器噪声、延迟、相机畸变、光照 |
| 系统 | 控制频率抖动、通信延迟、未建模的柔性 |

表中：

- **来源**：差距产生的类别；**例子**：典型表现
- 对比结论：执行器和接触是足式、操作类任务中最常见的差距来源

## 方法一：域随机化 (Domain Randomization)

训练时随机改变仿真参数，使策略见过足够多的「世界」，真实世界只是其中一个：

$$
\max_\pi\ \mathbb{E}_{\xi\sim p(\xi)}\ \mathbb{E}_{\tau\sim\pi,\ \xi}\left[\sum_{t}\gamma^{t} r_t\right]
$$

其中：

- $\pi$：策略；$\tau$：由策略与环境产生的轨迹
- $\xi$：随机化的环境参数（质量、摩擦、延迟、外力扰动、视觉纹理等）
- $p(\xi)$：参数的分布；范围太小则不鲁棒，太大则任务过难、策略保守
- $r_t$：第 $t$ 步奖励；$\gamma\in[0,1)$：折扣因子；$\mathbb{E}$：对参数和轨迹求期望
- 实践：随机化范围可由课程学习（自适应域随机化）逐渐放大

## 方法二：系统辨识与精确建模

用真机数据校准仿真模型：

$$
\hat{\theta}=\arg\min_\theta \sum_{t}\left\lVert s_{t+1}^{real}-f_\theta(s_t,a_t)\right\rVert^2
$$

其中：

- $\theta$：待辨识的模型参数（质量、摩擦、电机常数等）
- $s_t,a_t$：真机记录的状态与动作；$s_{t+1}^{real}$：下一时刻真实状态
- $f_\theta$：仿真模型预测的下一状态
- $\hat{\theta}$：使预测与真实最接近的参数；常结合激励轨迹采集数据

执行器网络：用神经网络拟合真机「指令 → 力矩」的映射，代替理想的电机模型，是足式机器人 sim2real 的有效做法。

## 方法三：自适应与在线学习

- **系统辨识型策略（RMA 等）**：策略接收环境参数的隐变量 $z$，在线用历史观测估计 $z$，适应不同环境
- **师生蒸馏**：教师策略在仿真中使用特权信息（真实摩擦、地形）训练；学生只用机载传感器，通过模仿教师学习
- **真机微调**：在真机上用少量数据继续训练，风险是安全与效率

## 方法四：缩小观测差距

- 视觉：域随机化纹理与光照、图像增强，或用域适应（如 CycleGAN）把仿真图转成真实风格
- 低维观测：只使用关节状态、IMU 等，感知差距更小
- 噪声与延迟：训练时加入传感器噪声和观测延迟

## 工程实践清单

- 动作空间：输出目标位置，再由底层 PD 控制器执行，比直接输出力矩更易迁移
- 平滑性：对动作变化加惩罚，避免真机抖动
- 安全：先在仿真里跑通边界条件，真机逐步增大难度，保留急停与限幅
- 评估：指标在仿真和真机中分别记录，对比差距，而不是只看仿真成绩
