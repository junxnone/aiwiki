# NLP

自然语言处理相关的常用数据集，待补充。常见类别：

| 任务   | 常用数据集    | 说明                 |
| ---- | -------- | ------------------ |
| 语言建模 | WikiText | 维基百科文本，用于语言模型训练和评估 |
| 文本分类 | IMDB     | 电影评论情感二分类          |
| 阅读理解 | SQuAD    | 基于文章回答问题           |
| 综合理解 | GLUE     | 多个自然语言理解任务的合集基准    |

表中：

  - **任务**：数据集面向的问题；**说明**：数据集的内容或用途
  - 对比结论：GLUE 一类的合集用于评估通用语言理解能力，单一数据集用于特定任务

大语言模型的评估见 [LLMs
Metrics](https://github.com/junxnone/aiwiki/issues/503)。其他类型的数据集见
[Datasets](https://github.com/junxnone/aiwiki/issues/17)。
