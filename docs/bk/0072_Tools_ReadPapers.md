# 论文阅读相关

读论文常用的网站和工具。

| 网站                                                           | 描述                          |
| ------------------------------------------------------------ | --------------------------- |
| [arxiv](https://arxiv.org/)                                  | 很多论文在顶会上发表后后续会开源发布到这个网站     |
| ~~[paperswithcode](https://www.paperswithcode.com/sota)~~ 已关 | 包含一些开源实现, 同类性能比较的网站         |
| [readpaper](https://readpaper.com/)                          | 中文阅读注释 paper 工具             |
| 豆包浏览器插件                                                      | 安装后在arxiv 上使用时会显示 `AI阅读` 按钮 |

表中：

  - **网站**：工具名称；**描述**：用途
  - 对比结论：找最新论文用 arxiv；需要快速读懂外文论文用 readpaper 或 AI 阅读插件

## 阅读流程

| 步骤 | 做什么       | 用到的工具                                                     |
| -- | --------- | --------------------------------------------------------- |
| 1  | 搜索并筛选论文   | arxiv                                                     |
| 2  | 先看摘要、图和结论 | 浏览器 / AI 阅读插件                                             |
| 3  | 精读方法与公式   | readpaper 的注释                                             |
| 4  | 找代码，复现实验  | 论文页面的 Code 链接                                             |
| 5  | 整理为笔记     | 见 [Papers](https://github.com/junxnone/aiwiki/issues/386) |

表中：对比结论：先快速筛选再精读，读完用笔记沉淀。更多资源见
[资源参考](https://github.com/junxnone/aiwiki/issues/380)。
