# AI 热点

按季度回顾 2020 年至今 AI
领域的热门方向、技术路线与应用行业，时间倒序排列（最新在前）。受限于截稿时间，部分近期内容可能不完整，仅供参考。

## 2026

### 2026 Q4（进行中）

  - Anthropic 发布 Claude Haiku 5.5（10月7日），低成本高吞吐模型成为 Agent 规模化部署的关键一环
  - 行业预测企业应用中具备任务型 Agent 的比例将在年底达到 40%（Gartner），Agent 推理算力成本预计增长 5 倍以上
  - "世界模型"（World Model）与视频生成、机器人仿真加速融合，成为继 LLM/Agent 之后的新焦点
  - **关键词**：Claude Haiku 5.5、企业级 Agent、推理成本、世界模型（World Model）
  - **发力领域**：低成本高吞吐推理部署、世界模型与机器人仿真融合

### 2026 Q3

  - Anthropic 发布 Claude Opus 5（7月24日）、Claude Opus 5.5（9月22日）、Claude
    Sonnet 5.5（9月28日）
  - Google 发布 Gemini 3.5 Flash-Lite（7月21日）、Gemini 3.8 Flash（9月2日）
  - 业界共识"2026 是 Agent 之年"：多智能体协作、Agent2Agent（A2A）协议、Model Context
    Protocol（MCP）成为标配，企业 Agent 工具调用成功率从 2025 年的 68% 提升至 89%
  - 具身智能/人形机器人行业进入"清场"阶段，头部企业集中度提升，竞争加剧
  - **关键词**：Claude Opus 5、Gemini 3.8 Flash、Agent 之年、A2A
    协议、MCP、多智能体协作、具身智能清场
  - **发力领域**：企业级 Agent 规模化部署、具身智能行业整合

### 2026 Q2

  - Anthropic 发布 Claude Sonnet 5（6月30日），取代 Sonnet 4.6 成为默认模型
  - 多 Agent 协作架构、标准化协议（A2A、MCP）打通生态壁垒，成为企业级 Agent 落地的核心支撑
  - **关键词**：Claude Sonnet 5、多 Agent 协作、标准化协议
  - **发力领域**：多智能体协同、跨平台互操作协议

### 2026 Q1

  - 国产大模型全球调用量反超海外厂商，百万级上下文从"实验室概念"变为"工业级标配"
  - Agent 智能体摆脱"玩具级应用"，开始规模化进入千行百业
  - Google 发布 Gemini 3 Deep Think 更新（2月12日）、Gemini 3.1 Pro（2月19日）
  - **关键词**：国产大模型、百万上下文、Agent 工业化、Gemini 3.1 Pro
  - **发力领域**：企业级 Agent 落地、长上下文工程化

## 2025

### 2025 Q4

  - Google 发布 Gemini 3（11月18日，含 Gemini 3 Pro / Deep Think）及 Gemini 3
    Flash（12月17日）
  - Anthropic 发布 Claude Sonnet 4.5（9月）
  - 人形机器人全年订单超 57 亿元，智元、宇树等企业出货量突破 5000+ 台，行业迎来"量产元年"
  - **关键词**：Gemini 3、Claude Sonnet 4.5、人形机器人量产元年
  - **发力领域**：深度推理（Deep Think）、人形机器人规模化生产

### 2025 Q3

  - OpenAI 发布 GPT-5（8月7日），统一推理与多模态能力于一体，替代 GPT-4o 成为 ChatGPT 默认模型
  - Anthropic 发布 Claude Opus 4.1（8月）
  - DeepSeek-R1 相关研究登上《Nature》封面，成为全球首个经权威同行评议的主流大语言模型
  - 宇树科技启动 IPO 申购
  - **关键词**：GPT-5、统一推理模型、DeepSeek-R1、Nature 封面、宇树 IPO
  - **发力领域**：统一推理与多模态融合、机器人商业化/资本化

### 2025 Q2

  - Anthropic 发布 Claude Opus 4 / Claude Sonnet 4（5月22日），支持长时间自主 Agent
    工作流，Claude Code 正式 GA
  - DeepSeek 发布 R1-0528 更新版（5月28日）
  - 宇树科技完成 C 轮融资（7亿元，估值120亿），具身智能领域融资全年共 370 起、总额超 419 亿元
  - **关键词**：Claude Opus 4/Sonnet 4、Claude Code、自主 Agent 工作流、具身智能融资热潮
  - **发力领域**：自主编程 Agent、长时间自动化任务、具身智能资本化

### 2025 Q1

  - DeepSeek-R1 发布（1月20日），开源推理模型性能比肩 OpenAI o1、训练成本仅约560万美元，引发"DeepSeek
    时刻"，一度导致英伟达股价下跌
  - Anthropic 发布 Claude 3.7 Sonnet（2月）
  - 具身智能/人形机器人领域融资与订单显著升温，智元机器人完成 B 轮融资
  - **关键词**：DeepSeek-R1、DeepSeek 时刻、开源推理模型、具身智能
  - **发力领域**：开源推理模型普惠、人形机器人与具身智能

## 2024

### 2024 Q4

  - Anthropic Claude 3.5 Sonnet 支持"computer use"（操作电脑，10月）
  - DeepSeek-V3 发布（12月），以低成本高效训练路线引发关注
  - Agent 开发框架（LangGraph 等）逐渐成熟，多步骤工具调用能力增强
  - **关键词**：Computer Use、DeepSeek-V3、低成本训练、Agent 框架
  - **发力领域**：自动化操作电脑（RPA 方向）、低成本大模型训练、智能体任务编排

### 2024 Q3

  - OpenAI 发布 o1（9月），首个主打"深度推理"（Chain-of-Thought + 强化学习）的模型，开启推理模型路线
  - 中国 Qwen2、DeepSeek-V2 等开源模型持续迭代
  - **关键词**：o1、推理模型、思维链、强化学习、开源大模型
  - **发力领域**：复杂推理（数学/代码）、开源模型迭代

### 2024 Q2

  - OpenAI 发布 GPT-4o（5月），原生多模态、实时语音交互
  - Meta 发布 Llama 3（4月）
  - Anthropic 发布 Claude 3.5 Sonnet（6月）
  - **关键词**：GPT-4o、原生多模态、实时语音、Llama 3
  - **发力领域**：实时语音交互、原生多模态理解、开源模型竞赛

### 2024 Q1

  - OpenAI 发布 Sora 文生视频模型（2月），视频生成与"世界模型"概念开始兴起
  - Google Gemini 1.5 实现百万级上下文窗口
  - Anthropic 发布 Claude 3 系列（3月）
  - **关键词**：Sora、文生视频、世界模型、长上下文
  - **发力领域**：视频生成、长上下文处理、科学/知识推理

## 2023

### 2023 Q4

  - OpenAI DevDay 发布 GPTs 自定义助手与 GPT-4 Turbo（11月）
  - Google 发布 Gemini（12月）
  - xAI 发布 Grok
  - **关键词**：GPTs、自定义助手、GPT-4 Turbo、Gemini
  - **发力领域**：个性化助手定制、多模态融合

### 2023 Q3

  - Meta 发布 Llama 2（7月），开放商用授权，推动开源大模型生态
  - GPT-4V 多模态能力开放
  - 中国发布《生成式人工智能服务管理暂行办法》等监管政策
  - **关键词**：Llama 2、开源商用、GPT-4V、AI 监管
  - **发力领域**：开源商用大模型、多模态视觉理解、AI 治理

### 2023 Q2

  - 基于 LLaMA 的开源微调模型（Alpaca、Vicuna 等）大量涌现
  - AutoGPT / BabyAGI 等自主 Agent 实验兴起，"AI Agent"概念首次大规模出圈
  - Google Bard 面向公众开放
  - **关键词**：开源微调、AutoGPT、AI Agent 元年、Bard
  - **发力领域**：自主智能体（Agent）探索、开源生态

### 2023 Q1

  - ChatGPT 用户数快速破亿；GPT-4 发布（3月14日）
  - Meta LLaMA 模型泄露（2月），催生开源社区繁荣
  - 百度文心一言等中国大模型密集发布
  - **关键词**：ChatGPT 出圈、GPT-4、LLaMA 泄露、文心一言
  - **发力领域**：通用多任务大模型、企业级大模型竞赛

## 2022

### 2022 Q4

  - OpenAI 发布 ChatGPT（11月30日），对话式 AI 现象级出圈，成为 AI 应用史的分水岭事件
  - **关键词**：ChatGPT、对话式 AI
  - **发力领域**：通用对话助手、内容生成全民化

### 2022 Q3

  - Stable Diffusion 开源发布（8月），文生图技术走向开源普惠
  - Midjourney 公测版上线（7月）
  - **关键词**：Stable Diffusion、文生图开源、Midjourney
  - **发力领域**：文生图产业化、创意设计

### 2022 Q2

  - OpenAI 发布 DALL·E 2（4月），大幅提升文生图质量
  - Google 发布 PaLM（540B 参数，4月），展示大模型涌现能力
  - DeepMind 发布 Flamingo 多模态模型
  - **关键词**：DALL·E 2、PaLM、涌现能力、多模态
  - **发力领域**：文生图、多模态理解、大规模语言理解

### 2022 Q1

  - DeepMind 发布 AlphaCode（2月），AI 在编程竞赛中达到中等水平程序员能力
  - **关键词**：AlphaCode、AI 编程
  - **发力领域**：自动化编程/算法竞赛

## 2021

### 2021 Q4

  - OpenAI 发布 Codex 论文，AI 编程助手赛道初现
  - DeepMind Gopher、RETRO 等大模型研究持续推进
  - **关键词**：Codex、AI 编程助手、Gopher、RETRO
  - **发力领域**：编程助手、通用大模型能力研究

### 2021 Q3

  - 扩散模型（Diffusion Model）相关研究升温，为后续文生图爆发埋下伏笔
  - **关键词**：扩散模型、Diffusion Model
  - **发力领域**：生成模型基础研究（图像）

### 2021 Q2

  - GitHub Copilot 技术预览发布（6月，基于 Codex），AI 辅助编程走向实用化
  - Google I/O 发布 LaMDA 对话模型
  - **关键词**：GitHub Copilot、AI 辅助编程、LaMDA
  - **发力领域**：代码生成/编程辅助、对话系统

### 2021 Q1

  - OpenAI 发布 DALL·E 与 CLIP（1月），文生图与图文对齐模型开端
  - **关键词**：DALL·E、CLIP、图文对齐
  - **发力领域**：图像生成、图文跨模态理解

## 2020

### 2020 Q4

  - DeepMind AlphaFold2 在 CASP14
    上取得突破性进展（11-12月），蛋白质结构预测问题被认为"接近解决"，AI4Science
    里程碑
  - **关键词**：AlphaFold2、蛋白质结构预测、AI4Science
  - **发力领域**：生物医药/蛋白质结构预测（AI4Science）

### 2020 Q3

  - GPT-3 API 开放测试（Beta），带动写作、客服、代码辅助等下游应用原型大量涌现
  - **关键词**：GPT-3 API、下游应用生态
  - **发力领域**：内容生成、智能客服、早期编程辅助

### 2020 Q2

  - OpenAI 发布 GPT-3（5月，1750亿参数），当时最大语言模型，few-shot learning 能力震撼业界
  - **关键词**：GPT-3、Few-shot Learning、大语言模型
  - **发力领域**：自然语言生成、少样本学习应用

### 2020 Q1

  - OpenAI 发布 Scaling Law 论文，为后续大模型规模化提供理论基础
  - **关键词**：Scaling Law、模型规模化
  - **发力领域**：自然语言处理理论基础
