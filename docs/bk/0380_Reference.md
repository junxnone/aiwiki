## 简介

| 资源             | 类型     | 用途                  |
| -------------- | ------ | ------------------- |
| paperswithcode | 论文与代码  | 按任务、方法查找论文并对应代码和排行榜 |
| arxiv          | 论文预印本  | 最新论文的来源             |
| ReadPaper      | 论文阅读   | 在线阅读与笔记             |
| labml.ai       | 代码解读   | 论文实现的逐行注释           |
| 动手学深度学习        | 教材     | 理论与代码结合的入门教程        |
| PaddleEdu      | 百科     | 深度学习概念与面试资源         |
| huggingface    | 模型与数据集 | 下载预训练模型、数据集，代码库     |

表中：对比结论：找论文用 paperswithcode 和 arxiv，学原理看教材，要用模型直接去 huggingface；数据集总览见
[Datasets](https://github.com/junxnone/aiwiki/issues/17)。
