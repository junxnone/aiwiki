# NARF - Normal Aligned Radial Feature

  - NARF 是**关键点检测 + 描述子**二合一的方法，专门面向\*\*深度图（Range
    Image）\*\*这种数据形式（而不是无序点云），常见于机器人用深度相机/激光雷达采集的场景数据。
  - 核心目标：找到"位于稳定表面、但邻域内存在明显物体边界"的点——这类点既不是平坦无特征的区域（没有判别力），也不是噪声剧烈的区域（不稳定），是关键点检测里"稳定性"和"显著性"的一个平衡点。

## 算法原理：关键点检测

1.  把点云转换成深度图表示（每个像素存储该方向上最近表面的距离）；
2.  对深度图上每个像素 $p$，在其局部邻域（大小 $s$）内，按照各邻域点到 $p$ 的 3D 距离排序，取排序后的**均值距离**
    $d\_M$；
3.  基于距离的变化模式，用启发式规则判断该像素附近是否存在**物体边界**（深度值发生跳变，即前景物体和背景之间的边缘）；
4.  综合"表面是否稳定"（法向量变化是否平缓）和"是否靠近物体边界"（上一步的边界检测结果）两个条件，筛选出同时满足"表面稳定+邻近有显著边界变化"的点，作为最终关键点。

## 描述子部分

在检测到的关键点上，NARF
还会计算一个描述子——以关键点为中心，沿不同方向采样邻域的深度变化模式，统计出一个能描述"物体边界在各个方向上形状"的特征向量，用于后续的关键点匹配。

## 和 Harris 3D 的互补关系

NARF 和 3D Cloud Features Harris 是点云关键点检测里两种常被放在一起比较的互补思路：NARF
专注于深度图上的**物体边界**附近的稳定点，Harris 3D 借鉴 2D
角点检测思路，专注于**曲率变化剧烈的角点**——两者关注的"显著性"定义不同，实践中常根据具体场景（边界敏感
vs 角点敏感）选择，或者两者结合使用增加关键点覆盖面。

## UseCase

NARF 常用于机器人场景下深度图之间的配准/物体识别——因为深度相机/激光雷达采集的数据天然就是深度图/距离图像形式，NARF
不需要额外转换成无序点云就能直接处理，在机器人导航、SLAM 场景里有历史上的广泛应用。
