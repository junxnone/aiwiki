# FGR - Fast Global Registration

FGR 是一种跳过"采样-验证"循环、直接对一个鲁棒目标函数做优化的全局配准算法——和
[SAC-IA](0300_3D_Algos_Registration_SACIA)/3D Algos Registration
4PCS/RANSAC 这类"随机采样+一致性验证"的框架完全不同，FGR
一步到位地在全部候选对应关系上做优化，不需要反复采样/验证/剔除候选对应，因此速度明显更快。

## 算法原理

1.  像 SAC-IA 一样，先用特征描述子（如 FPFH）在源点云和目标点云之间建立大量候选对应点对——这些候选里混杂着大量错误匹配；
2.  构造一个目标函数，对所有候选对应点对的配准残差求和，但**不是直接求和**，而是用一个\*\*鲁棒罚函数（Geman-McClure
    函数）\*\*包裹每一项残差——这个罚函数的特点是残差小时近似二次（和普通最小二乘一样），残差大到超过一定程度后增长趋于平缓（不再像平方误差那样对离群匹配的巨大残差"过度敏感"），天然抑制错误匹配对整体优化的影响；
3.  利用鲁棒估计和"线过程（Line Process）"理论之间的对偶关系，把这个非凸的 Geman-McClure
    目标函数改写成一组可以**交替优化**的子问题：固定权重求解变换矩阵、固定变换矩阵更新每个对应点对的权重（权重本质上表示"这对候选对应有多大概率是正确匹配"，自动实现了"验证+剔除"的效果，而不需要显式地采样/验证）；
4.  用\*\*渐进非凸化（Graduated Non-Convexity,
    GNC）\*\*策略：从一个更"温和"（接近凸）的目标函数开始优化，逐步过渡到真正的非凸目标，缓解直接优化非凸函数容易陷入差的局部最优的问题；
5.  迭代至收敛，得到最终的变换矩阵——整个过程不需要在内层循环里反复做最近邻查询（SAC-IA/ICP 都需要），这是 FGR
    速度优势的核心来源。

## 优点

  - **速度快**：没有内层最近邻查询，比传统"粗配准+精配准"两阶段流程快一个数量级以上，同时精度相当甚至更好；
  - **一步到位**：把粗配准（全局）和局部精修揉进同一个优化问题，不像传统流程需要先 SAC-IA 再 ICP 分两步做；
  - 可以扩展到多份点云同时全局对齐（多视角场景重建常见需求）。

## 缺点

  - **非凸优化没有全局最优保证**：渐进非凸化是分阶段近似求解，不保证找到真正的全局最优解；
  - **对极高离群匹配比例鲁棒性有限**：错误匹配比例特别高（一般认为超过 80%）时容易失败，这也是后续 TEASER/TEASER++
    等方法试图进一步改进的方向（能容忍高达 99% 的离群匹配）。

## 和其他方法的关系

FGR 和 [SAC-IA](0300_3D_Algos_Registration_SACIA) 都依赖特征描述子（如
FPFH）建立候选对应，区别在于处理错误匹配的方式：SAC-IA
用"随机采样+一致性打分"显式地做多轮试验，FGR
用鲁棒罚函数在一次优化里隐式地自动降低错误匹配的权重——是"采样验证范式"和"鲁棒优化范式"两条不同技术路线在同一个问题上的体现。
