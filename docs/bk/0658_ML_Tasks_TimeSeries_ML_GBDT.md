# GBDT

GBDT（Gradient Boosted Decision Trees，梯度提升决策树，论文脚注称 gradient tree
boosting 也叫 GBM 或 GBRT）是用一棵棵小回归树逐步叠加来拟合目标的方法：每加一棵树，就去修正前面所有树还没拟合好的部分。本文以
XGBoost（Chen & Guestrin，*XGBoost: A Scalable Tree Boosting
System*，[arXiv:1603.02754](https://arxiv.org/abs/1603.02754)，论文版权页注明
KDD '16）为依据讲算法原理，再讲它如何用于时序预测。

一句话概括：把时序预测改写成"滞后特征表 +
回归"问题，用加法树模型逐棵拟合（损失的二阶近似），靠正则化与高效的分裂搜索得到一个快、稳、对协变量友好的强基线。

**论文边界（先说清楚）**：XGBoost 论文是通用的树提升**系统**论文，实验只有分类（Allstate、Higgs）、排序（Yahoo
LTRC）和点击率预测（Criteo），**没有任何时序预测实验**，也没有讨论滞后特征、多步策略或外推问题。本文"用于时序预测"一章的做法全部来自实践经验，标
\[经验\]，口径与本站综述 [时间序列：机器学习方法](/0605_ML_Tasks_TimeSeries_ML) §3.1
一致。LightGBM、M5 比赛不在这篇论文里，本文只提名字，标 \[待核实\]。

时间线上的位置：XGBoost 论文发表于 2016 年；此后 XGBoost、LightGBM 等梯度提升树成为带特征工程的预测基线
\[经验\]，在 M5 等比赛中的表现 \[待核实\]。论文自己能支撑的只有：2015 年 Kaggle 博客公布的 29 个获胜方案中
17 个用了 XGBoost（脚注说明来自各比赛前 3 名团队的方案），且论文列举的问题示例里包含 store sales
prediction。

## 1\. 解决什么问题

### 1.1 论文的动机

论文引言说树提升在许多应用中表现突出，既可单独作预测器，也被用于广告点击率预测的生产管线。论文认为 XGBoost
成功的最重要因素是**可扩展性**：单机上比当时流行的方案快十倍以上，在分布式或内存受限场景可扩展到数十亿样本。论文列出的贡献：

  - 一个高度可扩展的端到端树提升系统；
  - 有理论保证的加权分位数草图（weighted quantile sketch），用于近似分裂的候选点；
  - 稀疏感知（sparsity-aware）的并行树学习算法；
  - 面向 out-of-core 学习的 cache-aware 块结构。

此外论文还提出了一个正则化的目标函数（作者称是"为完整起见"附带的改进）。

### 1.2 为什么时序预测会用它 \[经验\]

  - 时序预测一旦写成"一行 = 一个预测时刻的特征向量（滞后值、滚动统计、日历、协变量）"，就是标准的表格回归问题，GBDT
    是表格问题上最先该跑的强基线；
  - 业务预测常有大量类别/稀疏特征（商品、门店、促销、节假日 one-hot），XGBoost 的稀疏感知与缺失值处理正好对口；
  - 全局模型：成千上万条序列合并成一张大表训练一个模型，短序列和冷启动序列可借用跨序列共性，这正是 GBDT 擅长的数据规模。

## 2\. 核心算法（均来自论文 §2、§3）

### 2.1 加法树模型与正则化目标

给定 $n$ 个样本、$m$ 个特征的数据集 $\\mathcal D={(\\mathbf x\_i,y\_i)}$，用 $K$
棵回归树（CART）相加预测：

$$\\hat y\_i=\\phi(\\mathbf x\_i)=\\sum\_{k=1}^{K}f\_k(\\mathbf
x\_i),\\qquad f\_k\\in\\mathcal F$$

其中：$\\hat y\_i$ 是样本 $i$ 的预测；$\\phi$ 是整个加法模型；$K$ 是树的个数；$f\_k$ 是第 $k$
棵回归树，$\\mathcal F$ 是回归树的函数空间；预测是各树输出之和。

$\\mathcal F={f(\\mathbf x)=w\_{q(\\mathbf x)}}$（$q:\\mathbb
R^m\\to{1,\\dots,T}$，$w\\in\\mathbb R^T$）：$q$ 是树结构，把样本映射到叶子编号，$T$
是叶子数，$w\_j$ 是第 $j$
个叶子上的连续得分。与普通决策树不同，每个叶子带的是连续分数，最终预测是样本所落叶子分数之和。

学习的是下面的正则化目标：

$$\\mathcal L(\\phi)=\\sum\_i l(\\hat
y\_i,y\_i)+\\sum\_k\\Omega(f\_k),\\qquad \\Omega(f)=\\gamma
T+\\frac12\\lambda\\lVert w\\rVert^2$$

其中：$\\mathcal L(\\phi)$ 是总目标；$l$ 是损失函数；$\\Omega(f)$ 是单棵树的复杂度惩罚；$\\gamma$
惩罚叶子数 $T$；$\\lambda$ 是叶权重的 $L\_2$ 正则强度；$w$ 是叶权重向量。

$l$ 是可微的凸损失；$\\Omega$ 惩罚叶子数 $T$
与叶权重的平方范数。论文指出：正则项让最终学到的权重更平滑以避免过拟合；$\\lambda$
取 0 时退化为传统的梯度树提升；该目标比 RGF（regularized greedy forest）更简单、更易并行。

### 2.2 逐棵加树与二阶近似

目标里的"参数"是函数，不能在欧氏空间里直接优化，于是以加法方式训练：记 $\\hat y\_i^{(t-1)}$ 为前 $t-1$
轮的预测，第 $t$ 轮贪心地加一棵 $f\_t$：

$$\\mathcal L^{(t)}=\\sum\_{i=1}^{n}l\\bigl(y\_i,\\hat
y\_i^{(t-1)}+f\_t(\\mathbf x\_i)\\bigr)+\\Omega(f\_t)$$

其中：$\\mathcal L^{(t)}$ 是第 $t$ 轮目标；$l$ 是损失；$y\_i$ 是真实值；$\\hat
y\_i^{(t-1)}$ 是前 $t-1$ 轮的预测；$f\_t$ 是新加的树；$\\Omega(f\_t)$ 是其复杂度惩罚。

对 $l$ 做二阶泰勒展开：

$$\\mathcal L^{(t)}\\simeq\\sum\_{i=1}^{n}\\Bigl\[l\\bigl(y\_i,\\hat
y^{(t-1)}\\bigr)+g\_if\_t(\\mathbf x\_i)+\\frac12h\_if\_t^2(\\mathbf
x\_i)\\Bigr\]+\\Omega(f\_t)$$

其中：$l(y\_i,\\hat y^{(t-1)})$ 是已有预测的损失（常数项）；$g\_i,h\_i$
分别是损失对预测的一阶、二阶导；$f\_t(\\mathbf x\_i)$
是新树的输出；$\\Omega(f\_t)$ 是正则项；这是损失的二阶泰勒展开。

其中 $g\_i=\\partial\_{\\hat y^{(t-1)}},l\\bigl(y\_i,\\hat
y^{(t-1)}\\bigr)$、$h\_i=\\partial^2\_{\\hat
y^{(t-1)}},l\\bigl(y\_i,\\hat y^{(t-1)}\\bigr)$ 是一阶、二阶梯度统计量。去掉常数项，第 $t$
步的简化目标为：

$$\\tilde{\\mathcal L}^{(t)}=\\sum\_{i=1}^{n}\\Bigl\[g\_if\_t(\\mathbf
x\_i)+\\frac12h\_if\_t^2(\\mathbf x\_i)\\Bigr\]+\\Omega(f\_t)$$

其中：$g\_i,h\_i$ 是样本 $i$ 的一阶、二阶梯度；$f\_t(\\mathbf x\_i)$ 是新树对样本 $i$
的输出；$\\Omega(f\_t)$ 是新树的复杂度惩罚；去掉常数项后得到简化目标。

记叶子 $j$ 上的样本集合 $I\_j={i\\mid q(\\mathbf x\_i)=j}$，展开 $\\Omega$ 后按叶子重组：

$$\\tilde{\\mathcal
L}^{(t)}=\\sum\_{j=1}^{T}\\Bigl\[\\Bigl(\\sum\_{i\\in
I\_j}g\_i\\Bigr)w\_j+\\frac12\\Bigl(\\sum\_{i\\in
I\_j}h\_i+\\lambda\\Bigr)w\_j^2\\Bigr\]+\\gamma T$$

其中：$j$ 是叶子编号，$T$ 是叶子数；$w\_j$ 是叶子 $j$ 的权重；$I\_j$ 是叶子 $j$
内的样本集合；$g\_i,h\_i$ 是样本的一阶、二阶梯度；$\\lambda,\\gamma$ 是正则系数。

这是关于每个 $w\_j$ 的一元二次函数。固定树结构 $q$，最优叶权重与对应的最优目标值为：

$$w\_j^{\*}=-\\frac{\\sum\_{i\\in I\_j}g\_i}{\\sum\_{i\\in
I\_j}h\_i+\\lambda}$$

其中：$w\_j^{\*}$ 是叶子 $j$ 的最优权重；$g\_i,h\_i$ 是样本的一阶、二阶梯度；$I\_j$ 是叶子 $j$
内的样本；$\\lambda$ 是正则强度，使叶权重向 0 收缩。

$$\\tilde{\\mathcal
L}^{(t)}(q)=-\\frac12\\sum\_{j=1}^{T}\\frac{\\bigl(\\sum\_{i\\in
I\_j}g\_i\\bigr)^2}{\\sum\_{i\\in I\_j}h\_i+\\lambda}+\\gamma T$$

其中：$\\tilde{\\mathcal L}^{(t)}(q)$ 是树结构 $q$ 的最优目标值（越小越好）；$I\_j$ 是叶子 $j$
的样本集合；$T$ 是叶子数；$\\gamma T$ 是叶子数惩罚；可作为树结构的打分函数。

后者可当作树结构的打分函数，作用类似决策树的不纯度，但适用于更广的目标函数（得分越小越好）。

### 2.3 分裂增益

不可能枚举所有树结构，实际用贪心：从单个叶子出发迭代地加分支。设某节点样本集 $I=I\_L\\cup I\_R$
被分成左右两部分，损失下降量（论文 Eq. 7，实践中用来评估候选分裂）为：

$$\\mathcal L\_{split}=\\frac12\\left\[\\frac{\\bigl(\\sum\_{i\\in
I\_L}g\_i\\bigr)^2}{\\sum\_{i\\in
I\_L}h\_i+\\lambda}+\\frac{\\bigl(\\sum\_{i\\in
I\_R}g\_i\\bigr)^2}{\\sum\_{i\\in
I\_R}h\_i+\\lambda}-\\frac{\\bigl(\\sum\_{i\\in
I}g\_i\\bigr)^2}{\\sum\_{i\\in I}h\_i+\\lambda}\\right\]-\\gamma$$

其中：$I\_L,I\_R,I$ 是左子节点、右子节点与父节点的样本集合；$g\_i,h\_i$ 是样本的一阶、二阶梯度；$\\lambda$
是叶权重的 $L\_2$ 正则强度；$\\gamma$ 是新增叶子的复杂度代价；该式为分裂后损失的下降量，越大越值得分裂。

最后的 $-\\gamma$ 是新增一个叶子的复杂度代价：增益不足 $\\gamma$ 的分裂不值得做。

**自拟示意算例（非论文数字，已手算）**：取 $l=\\frac12(y-\\hat y)^2$，则 $g\_i=\\hat
y\_i-y\_i$、$h\_i=1$。初始 $\\hat y=0$，四个样本 $y=(2,3,8,9)$，故
$g=(-2,-3,-8,-9)$，$h=(1,1,1,1)$；取 $\\lambda=1,\\gamma=0$。

  - 分裂
    A：${2,3}\\mid{8,9}$：$G\_L=-5,H\_L=2$；$G\_R=-17,H\_R=2$；$G=-22,H=4$。增益
    $=\\frac12\\bigl\[\\frac{25}{3}+\\frac{289}{3}-\\frac{484}{5}\\bigr\]=\\frac12\\times7.8667\\approx3.93$。叶权重
    $w\_L=5/3\\approx1.67$，$w\_R=17/3\\approx5.67$。
  - 分裂 B：${2}\\mid{3,8,9}$：$G\_L=-2,H\_L=1$；$G\_R=-20,H\_R=3$。增益
    $=\\frac12\\bigl\[\\frac{4}{2}+\\frac{400}{4}-\\frac{484}{5}\\bigr\]=\\frac12\\times5.2=2.6$。

A 的增益更大，被选中。注意 $w^\*$ 比"叶内均值"（2.5 与 8.5）小，这是 $\\lambda$ 把叶权重向 0 收缩的效果。

### 2.4 Shrinkage 与列采样

论文用了两个额外的防过拟合手段：

  - **Shrinkage**（Friedman 提出）：每步提升后把新加的权重乘一个因子
    $\\eta$，类似学习率，降低单棵树的影响，给后续的树留出改进空间。
  - **列（特征）子采样**：借自
    RandomForest；论文称据用户反馈，列采样比传统的行采样更能防过拟合（行采样也支持），并能加速后文的并行算法。

### 2.5 分裂搜索算法

找最佳分裂是树学习的关键开销。论文给出三层：

**精确贪心（Alg. 1）**：对每个特征，按取值排序后线性扫描，累计 $G\_L,H\_L$，用 $G\_R=G-G\_L,\\
H\_R=H-H\_L$ 算每个候选点的得分，取最大。单机支持，但数据放不进内存或分布式时不可行。

**近似算法（Alg. 2）**：按特征分布的百分位提出候选分裂点
$S\_k={s\_{k1},\\dots,s\_{kl}}$，把连续特征映射进桶，聚合桶内的
$G,H$，只在候选点中找最优。有两种变体：全局（global，建树之初一次性提出候选，所有层共用，所需候选更多）与局部（local，每次分裂后重新提出，更适合更深的树）。论文在
Higgs 10M 上的 Fig. 3
中报告：局部提案所需候选更少，全局提案在候选足够多时可以和局部一样准；分位数策略在合理的近似程度下能达到与精确贪心相同的精度。

**加权分位数草图（§3.3）**：候选点不是按样本个数取分位，而是按二阶梯度 $h\_i$ 加权。理由是把
$\\tilde{\\mathcal L}^{(t)}$ 改写后得到

$$\\sum\_{i=1}^{n}\\frac12h\_i\\Bigl(f\_t(\\mathbf
x\_i)-\\frac{g\_i}{h\_i}\\Bigr)^2+\\Omega(f\_t)+\\text{constant}$$

其中：$g\_i,h\_i$ 是一阶、二阶梯度；$f\_t$ 是第 $t$ 棵树；$g\_i/h\_i$ 可看作标签、$h\_i$
是样本权重，因此该目标等价于加权平方损失；$\\Omega(f\_t)$ 是正则项。

即标签为 $g\_i/h\_i$、权重为 $h\_i$ 的加权平方损失，所以 $h\_i$ 就是样本权重。对第 $k$ 个特征，令多重集
$\\mathcal D\_k={(x\_{1k},h\_1),\\dots,(x\_{nk},h\_n)}$，定义秩函数

$$r\_k(z)=\\frac{1}{\\sum\_{(x,h)\\in\\mathcal
D\_k}h}\\sum\_{(x,h)\\in\\mathcal D\_k,\\ x\<z}h$$

其中：$\\mathcal D\_k$ 是第 $k$ 个特征的（取值，二阶梯度）多重集；$x\_{ik}$ 是样本 $i$ 的第 $k$
个特征值；$h\_i$ 是其二阶梯度（样本权重）；$r\_k(z)$ 是特征值小于 $z$ 的样本所占的加权比例。

它表示特征值小于 $z$ 的样本所占的（加权）比例。候选点 ${s\_{k1},\\dots,s\_{kl}}$ 要满足

$$\\lvert r\_k(s\_{k,j})-r\_k(s\_{k,j+1})\\rvert\<\\epsilon,\\qquad
s\_{k1}=\\min\_i x\_{ik},\\quad s\_{kl}=\\max\_i x\_{ik}$$

其中：$s\_{k,j}$ 是第 $k$ 个特征的第 $j$ 个候选分裂点；$r\_k$ 是秩函数；$\\epsilon$
是近似因子；相邻候选点之间的加权占比差小于
$\\epsilon$；首末候选点是特征的最小值与最大值。

$\\epsilon$ 是近似因子，大致对应 $1/\\epsilon$ 个候选点。论文称当时没有适用于加权数据的分位数草图，它提出的结构支持
merge 与 prune 操作并给出可证明的精度保证（细节与证明在论文附录，本文不展开）。

**稀疏感知分裂（§3.4, Alg. 3）**：输入稀疏有三类原因：缺失值、统计量里大量零、one-hot
之类特征工程的产物。做法是给每个树节点加一个**默认方向**：特征值缺失时样本走默认方向；对每个分裂，分别枚举"缺失值全走右"和"缺失值全走左"两种情形，取增益最大者，因此最优默认方向是从数据里学出来的。关键是只遍历非缺失项，复杂度与非缺失项个数成线性。论文在
Allstate-10K 上报告稀疏感知算法比朴素实现快 50 倍以上（Fig. 5）。

下图示意带默认方向的树节点。

    树节点（示意，对应论文 Fig. 4；分裂条件：age < 20）
       ├─ 是 ──→ ...
       ├─ 否 ──→ ...
       └─ 特征缺失 ──→ 走训练中学到的默认方向（左或右）

图中：这是一个树节点的示意：按条件（如 age \<
20）把样本分到"是"与"否"两个分支，特征缺失的样本走训练中学到的默认方向（左或右）。关键结论：默认方向由数据决定，使缺失值无需额外填补。

## 3\. 系统设计（论文 §4）

论文把算法和系统一起优化。要点：

**列块（column block）**：排序是树学习中最耗时的部分，所以数据以块为单位按 CSC
格式存放，每列按特征值预排序，只在训练前算一次、后续迭代复用。精确贪心把整个数据集放进一个块，对块做一次线性扫描就能同时收集所有叶子上的候选分裂统计量；近似算法可使用多个块（每块对应一部分行），块可分布到不同机器或放在磁盘上。块结构也便于列采样。复杂度分析（$d$
为树的最大深度，$K$ 为树数，$\\lVert\\mathbf x\\rVert\_0$ 为训练数据中非缺失项个数）：

$$O\\bigl(Kd\\lVert\\mathbf x\\rVert\_0\\log n\\bigr)\\
\\longrightarrow\\ O\\bigl(Kd\\lVert\\mathbf x\\rVert\_0+\\lVert\\mathbf
x\\rVert\_0\\log n\\bigr)$$

其中：$K$ 是树的个数；$d$ 是树的最大深度；$\\lVert\\mathbf x\\rVert\_0$ 是训练数据中非缺失项个数；$n$
是样本数；$q$ 是候选分裂点数；$B$ 是每个块的最大行数；箭头左侧是未预排序的复杂度，右侧是列块预排序后摊销 $\\log$
因子的复杂度。

即精确贪心中省掉每棵树内的 $\\log n$ 因子（预处理一次性摊销）；近似算法从 $O(Kd\\lVert\\mathbf
x\\rVert\_0\\log q)$ 降到 $O(Kd\\lVert\\mathbf x\\rVert\_0+\\lVert\\mathbf
x\\rVert\_0\\log B)$，$q$ 为候选点数（通常 32 到 100），$B$ 为每块最大行数。

**Cache-aware 访问**：按特征顺序扫描时，需要按行索引间接读取梯度统计量，是非连续内存访问，统计量放不进 CPU cache
时会因 cache miss 变慢。精确贪心用预取（每线程一个内部缓冲，先取后累加）缓解，论文称数据集大时快一倍（Fig.
7，10M 规模）；近似算法通过选合适的块大小解决，论文实验得出每块 $2^{16}$ 个样本较均衡：块太小并行效率低，块太大会 cache
miss（Fig. 9）。

**Out-of-core**：数据分块存盘，用独立线程预取到内存缓冲。两项技术：块压缩（按列压缩、读入时由独立线程解压，行索引用 16
位偏移存储，因此每块 $2^{16}$ 个样本，多数数据集上压缩率约 26% 到
29%）与块分片（把数据交替分到多块磁盘，每块盘一个预取线程）。

## 4\. 实验与结论（论文自己的数字）

通用设置：最大深度 8、shrinkage 0.1、除非另说不做列采样。单机实验在 Dell PowerEdge R420（两颗八核 Xeon
E5-2470、64GB 内存）上。

数据集（论文 Table 2）：

| 数据集         | $n$   | $m$  | 任务     |
| ----------- | ----- | ---- | ------ |
| Allstate    | 10 M  | 4227 | 保险理赔分类 |

表中：「数据集」是四个评测集，$n$ 是样本数，$m$ 是特征数，「任务」是其应用类型；M 为百万，B 为十亿。

**分类（Higgs-1M，500 棵树，精确贪心，论文 Table 3）**：

## 5\. 优缺点与局限

论文自述的取舍：

  - 近似算法需要在候选点数与精度间折中；
  - 精确贪心不适合放不进内存的数据；
  - 论文的结论是系统性的（可扩展、省资源），不是对某类数据的精度保证。

\[经验\] 用于时序预测时：

| 优点                                                  | 缺点                                                           |
| --------------------------------------------------- | ------------------------------------------------------------ |
| 快、CPU 即可；对异构协变量、类别特征友好；能处理缺失值；特征重要性便于诊断；业务预测里长期是强基线 | 不外推趋势；特征工程依赖人；多步预测要选策略且各步长不保证一致；默认只给点预测；对结构突变与长历史依赖不如专门的序列模型 |

表中：左列是 GBDT 用于时序预测的优点，右列是缺点。结论：它是快速稳健的强基线，但需要手工特征、不外推趋势、默认只给点预测。

## 6\. 用于时序预测 \[经验\]

本章内容论文里**没有**，全部标 \[经验\]，与[综述 §3.1](/0605_ML_Tasks_TimeSeries_ML)口径一致。

### 6.1 把序列变成特征表

对每个预测时刻 $t$ 构造一行：目标 $y\_{t}$（或 $y\_{t+h}$）；特征包括滞后值
$y\_{t-1},y\_{t-7},\\dots$、滚动窗口统计（均值、标准差、最近 28 天均值等，必须只用 $t$
之前的数据）、日历特征（星期、月、节假日）、协变量（价格、促销，未来已知的可用未来值）、静态特征（序列
ID、类别）。常见错误是特征窗口包含了目标时刻或之后的信息（数据泄漏）。

### 6.2 多步预测策略

| 策略   | 做法                       | 说明                  |
| ---- | ------------------------ | ------------------- |
| 递归   | 一个单步模型，把预测值作为下一步的滞后输入    | 只训一个模型；$H$ 长时误差累积明显 |
| 直接   | 每个步长 $h$ 一个模型，或把 $h$ 当特征 | 业务预测常用做法，模型数多或表变大   |
| MIMO | 一个模型同时输出多步               | GBDT 不原生支持，需要包装     |

表中：「策略」是多步预测方式，「做法」说明实现，「说明」比较误差累积与模型数量。结论：业务预测常用直接策略；递归策略在 $H$
长时误差累积明显。

### 6.3 外推问题与目标变换

决策树把特征空间分成若干区域，每个区域输出一个常数，集成后仍是分段常数函数，因此一般不能像线性模型那样外推趋势 \[经验\]（综述 §1.6
的说法；严格的取值范围取决于具体设置）。训练期水平在 $\[80,120\]$、测试期升到 $\[130,170\]$
时，直接对水平值回归会系统性低估。做法：预测相对比值 $y\_t/\\bar y\_{t-28:t-1}$
再乘回近期均值；对序列做差分；或用线性项抓趋势、树抓非线性残差。

### 6.4 时序交叉验证

不能随机打乱划分。用按时间向前滚动的划分：训练窗只在验证窗之前，且在训练与验证之间留出至少等于预测步长的间隔以避免泄漏 \[经验\]。

### 6.5 概率预测

把损失换成分位数（pinball）损失，每个分位数水平训练一个模型，可能出现分位数交叉，需要排序修正；或"点预测 + 共形校准"。Poisson
/ Tweedie 目标用于非负、大量零值的需求。具体见综述 §3.3。

## 7\. 与相关方法对比

| 方法                                                                                        | 定位                        | 与 GBDT 的关系                       |
| ----------------------------------------------------------------------------------------- | ------------------------- | -------------------------------- |
| LightGBM                                                                                  | 另一个梯度提升树实现，不在本论文中 \[待核实\] | 同类方法，本文不展开、不比较                   |
| 随机森林                                                                                      | 论文借用其列采样                  | 平均而非逐棵修正，同样不外推 \[经验\]            |
| [ARIMA](/0624_ML_Tasks_TimeSeries_Classical_ARIMA)                                        | 局部、线性、可外推                 | GBDT 是全局、非线性、需特征工程 \[经验\]        |
| [DeepAR](/0625_ML_Tasks_TimeSeries_Deep_DeepAR)、[TCN](/0626_ML_Tasks_TimeSeries_Deep_TCN) | 深度序列模型                    | 自动学表示，需要更多数据与调参；对比需同等调参预算 \[经验\] |

表中：「方法」是对比对象，「定位」说明其性质，「与 GBDT 的关系」说明联系与区别。结论：GBDT
是全局、非线性、依赖特征工程的方法，与线性局部模型和深度序列模型互补。

## 8\. 使用方式

示意代码，未运行验证（xgboost + 滞后特征 + 时序划分，直接策略 $h=7$）：

``` python
import pandas as pd
import xgboost as xgb
from sklearn.model_selection import TimeSeriesSplit

H = 7
df["lag1"] = df["y"].shift(1)
df["lag7"] = df["y"].shift(7)
df["roll28"] = df["y"].shift(1).rolling(28).mean()
df["dow"] = df.index.dayofweek  # 假设索引是日期
df["target"] = df["y"].shift(-H)
data = df.dropna()
X, y = data[["lag1", "lag7", "roll28", "dow"]], data["target"]

model = xgb.XGBRegressor(n_estimators=500, learning_rate=0.1,
                         max_depth=6, subsample=0.8, colsample_bytree=0.8)
for tr, va in TimeSeriesSplit(n_splits=5).split(X):
    model.fit(X.iloc[tr], y.iloc[tr])
    pred = model.predict(X.iloc[va])
```

上面只训练了 $h=7$ 一个步长；直接策略要对每个 $h$ 重复，或把 $h$ 作为特征。实际使用中特征、滚动统计和划分必须保证不泄漏未来信息
\[经验\]。
