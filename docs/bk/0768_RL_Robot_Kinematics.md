# Kinematics

不考虑力，只研究机械臂关节变量与末端位姿之间的几何关系：正运动学、逆运动学、雅可比与奇异性。所属总览见 [RL
Robot](https://github.com/junxnone/aiwiki/issues/458)，变换基础见 RL Robot
Transform。

## 问题定义

``` mermaid
flowchart LR
    Q[关节空间 q] -- 正运动学 FK --> X[任务空间 x]
    X -- 逆运动学 IK --> Q
    Q -- 雅可比 J --> V[末端速度]
```

图中：

  - 关节空间：关节变量 $q=(q\_1,\\dots,q\_n)$，即位形空间
  - 任务空间：末端位姿 $x$，如 $SE(3)$ 中的 $T$
  - 箭头：FK 由 $q$ 求 $x$（唯一、直接）；IK 由 $x$ 求 $q$（可能无解、多解）；雅可比 $J$ 连接两者的速度
  - 关键结论：FK 容易、IK 困难

## 正运动学 (FK)

对 $n$ 个关节的串联机械臂，末端位姿为各连杆变换连乘（指数积 / DH 均可）：

$$ T\_{0n}(q)=T\_{01}(q\_1),T\_{12}(q\_2)\\cdots T\_{n-1,n}(q\_n) $$

其中：

  - $q\_i$：第 $i$ 个关节变量（转动关节为角度，移动关节为位移）
  - $T\_{i-1,i}(q\_i)$：第 $i$ 个连杆相对前一个的齐次变换
  - $T\_{0n}$：末端相对基座的位姿

### DH 参数

用 4 个参数描述相邻连杆的几何关系：

$$
T\_{i-1,i}=R\_z(\\theta\_i),\\mathrm{Trans}\_z(d\_i),\\mathrm{Trans}\_x(a\_i),R\_x(\\alpha\_i)
$$

其中：

  - $\\theta\_i$：绕 $z\_{i-1}$ 轴的关节角（转动关节的变量）
  - $d\_i$：沿 $z\_{i-1}$ 轴的连杆偏距（移动关节的变量）
  - $a\_i$：沿 $x\_i$ 轴的连杆长度
  - $\\alpha\_i$：绕 $x\_i$ 轴的连杆扭角
  - 注意：DH 有标准与改进（Craig）两种约定，下标与顺序不同，使用前要确认

## 逆运动学 (IK)

给定目标位姿 $x\_d$，求满足 $f(q)=x\_d$ 的 $q$，其中 $f$ 为 FK 函数。

  - 无解：目标超出工作空间
  - 多解：如「肘上/肘下」构型，6 轴臂最多 16 组解
  - 无穷多解：冗余机械臂（$n\>6$），可借助零空间优化次级目标
  - 方法：解析法（如球腕机构，Pieper 准则）、数值法（见下）

数值法（牛顿迭代 / 阻尼最小二乘）：

$$ \\Delta q = J^{\\top}\\left(JJ^{\\top}+\\lambda^2
I\\right)^{-1},e,\\qquad q\\leftarrow q+\\Delta q $$

其中：

  - $e=x\_d-f(q)$：当前位姿误差
  - $J$：雅可比矩阵
  - $\\lambda$：阻尼系数；靠近奇异点时抑制 $\\Delta q$ 过大，$\\lambda=0$ 退化为伪逆
  - 迭代到 $\\lVert e\\rVert$ 小于阈值为止，初值选得好坏会影响收敛到哪个解

## 雅可比矩阵

$$ \\dot{x}=J(q),\\dot{q} $$

其中：

  - $\\dot{q}\\in\\mathbb{R}^n$：关节速度
  - $\\dot{x}\\in\\mathbb{R}^6$：末端空间速度（线速度 $v$ + 角速度 $\\omega$）
  - $J(q)\\in\\mathbb{R}^{6\\times n}$：雅可比矩阵，依赖当前位形；第 $i$ 列是关节 $i$
    单位速度引起的末端运动
  - 同时由虚功原理：$\\tau=J^{\\top}F$，关节力矩 $\\tau$ 与末端力 $F$ 通过 $J^{\\top}$ 对应

## 奇异性

当 $\\operatorname{rank}J(q)\<6$（或 $\\det J=0$）时机械臂处于**奇异位形**：

  - 末端在某些方向上无法运动
  - 为在这些方向产生速度，关节速度趋于无穷
  - 典型情形：臂完全伸直、腕部两轴共线
  - 可操作度指标：$w=\\sqrt{\\det(JJ^{\\top})}$，越接近 0 越靠近奇异

其中 $w$ 是 Yoshikawa 可操作度，$JJ^{\\top}$ 的特征值反映各方向的运动能力。
