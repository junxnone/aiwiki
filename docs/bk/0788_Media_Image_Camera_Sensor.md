# Sensor

图像传感器：CCD 与 CMOS 的区别，全局快门与卷帘快门，像素尺寸、传感器尺寸、视场角与分辨率之间的关系，以及面阵和线阵相机。

## CCD 与 CMOS

两者都是把光子变成电荷再变成电压，区别在于读出方式：

``` mermaid
flowchart LR
    subgraph CCD
        P1[像素: 光电转换] --> T1[电荷逐行转移] --> O1[单个输出放大器] --> ADC1[ADC]
    end
    subgraph CMOS
        P2[像素: 光电转换 + 放大器] --> C2[列并行读出] --> ADC2[列 ADC]
    end
```

图中：

  - CCD 把各像素的电荷依次转移到一个公共输出口，再统一放大和转换，一致性好，但读出慢、功耗高、需要特殊工艺
  - CMOS 每个像素自带放大器，可以按列并行读出和 AD 转换，速度快、功耗低、成本低，还能把更多电路集成到同一芯片

对比：

| 维度     | CCD              | CMOS      |
| ------ | ---------------- | --------- |
| 读出方式   | 电荷转移，单输出口        | 像素内放大，列并行 |
| 速度     | 较慢               | 快，高帧率     |
| 功耗/成本  | 高                | 低         |
| 噪声/一致性 | 早期更好             | 近年已追平甚至更优 |
| 快门     | 通常全局             | 全局或卷帘     |
| 现状     | 逐步淘汰，用于少数科学/特殊相机 | 目前主流      |

表中：`快门` 一行见下一节。现代工业相机和手机几乎都是 CMOS，选型时更多是看具体型号的参数，而不是简单认为 CCD 画质更好。

## 快门

下图对比两种快门读出方式在曝光时间轴上的差别：

``` mermaid
gantt
    title 曝光时间轴示意
    dateFormat X
    axisFormat %s
    section 全局快门
    所有行同时曝光 :a1, 0, 4
    section 卷帘快门
    第1行 :b1, 0, 4
    第2行 :b2, 1, 5
    第3行 :b3, 2, 6
    第4行 :b4, 3, 7
```

图中：

  - 横轴是时间，每条横条是某一行像素的曝光时段
  - 全局快门 (global shutter)：所有行在同一时刻开始、同一时刻结束，整幅图是同一瞬间的快照
  - 卷帘快门 (rolling shutter)：每行起止时间依次错开，后面的行比前面的行晚曝光一个行延迟
  - 拍摄运动物体时，卷帘快门会使不同行记录到物体在不同时刻的位置，造成倾斜、扭曲 (果冻效应)

卷帘快门造成的位移近似为：

$$ \\Delta x \\approx v\\cdot T\_{readout} $$

其中：

  - $v$：物体在图像上的运动速度 (像素/秒)
  - $T\_{readout}$：从第一行到最后一行读出的总时间 (秒)
  - $\\Delta x$：顶部和底部之间的错位量 (像素)；例：物体速度 $2000\\text{px/s}$，读出时间
    $10\\text{ms}$，错位约 20 像素
  - 运动物体检测、飞拍等场景必须选全局快门，见 [定拍 vs 飞拍](/0038_Media_Image_Camera_定拍飞拍)

## 像素尺寸与传感器尺寸

  - 像素尺寸 $dx,dy$：单个像素的物理宽高，单位 μm，见 [dx
    dy](/0546_Media_Image_Camera_相机内参_dxdy)
  - 传感器尺寸常用英寸表示 (如 `1/2.3"`、`1"`)，这是历史上摄像管的外径，不是传感器对角线的真实长度，实际对角线约为标称值的
    $2/3$ 左右
  - 在同一传感器面积下，分辨率越高像素越小，单个像素收集的光越少，信噪比越低；同一像素数下传感器越大，通常越灵敏

$$ \\text{FOV}=2\\arctan\!\\left(\\frac{d}{2f}\\right),\\qquad
\\text{GSD}=\\frac{\\text{FOV}*{物方}}{N*{px}} $$

其中：

  - $d$：传感器在对应方向上的物理尺寸 (宽或高，mm)；$f$：镜头焦距 (mm)
  - $\\text{FOV}$：该方向的视场角；焦距越短，视场越大
  - $\\text{FOV}*{物方}$：工作距离处物体平面上可见的实际长度；$N*{px}$：该方向的像素数
  - $\\text{GSD}$ (这里指物方分辨率)：每个像素对应的物理长度 (mm/pixel)；视觉测量里要看清 $x$
    大小的缺陷，一般要求至少几个像素跨过它，因此要先用这个量反算相机分辨率和镜头

## 面阵与线阵

| 类型               | 结构                   | 适用                                   |
| ---------------- | -------------------- | ------------------------------------ |
| 面阵相机 (Area Scan) | 二维像素阵列，一次曝光得到一幅图     | 绝大多数场景，目标静止或可触发拍照                    |
| 线阵相机 (Line Scan) | 一行或几行像素，随物体运动逐行扫描拼成图 | 连续运动的长材料 (卷材、印刷品、带钢)，需要极高分辨率         |
| 3D 相机            | 输出深度或点云              | 见 [3D 图像](/0039_Media_Image_3DImage) |

表中：线阵相机要求物体与相机之间有相对运动，并需要编码器同步，行频必须与运动速度匹配，才能保证 X、Y 方向像素等比例。

## 彩色与黑白

  - 彩色传感器带有 Bayer 滤光片，每个像素只能测一种颜色，需要去马赛克，有效分辨率和灵敏度都低于黑白，见
    [Bayer](/0784_Media_Image_Bayer)
  - 工业测量、定位、缺陷检测只需要灰度信息时，优先选黑白相机
  - 输出的像素格式见 [像素格式](/0119_Media_Image_Camera_PixelFormat)，处理流程见
    [ISP](/0785_Media_Image_ISP)

## 主要指标

| 指标      | 含义                                                                   |
| ------- | -------------------------------------------------------------------- |
| 分辨率     | 像素数，如 $1920\\times1200$                                              |
| 像素尺寸    | 单位 μm，影响灵敏度                                                          |
| 帧率      | 每秒输出多少帧，受读出速度和接口带宽限制                                                 |
| 量子效率 QE | 入射光子被转换成电子的比例                                                        |
| 动态范围 DR | 最大不饱和信号与噪声底的比值，单位 dB，决定能同时拍清多大的明暗差异                                  |
| 位深      | 输出每像素位数，8/10/12 bit                                                  |
| 接口      | GigE、USB3、CoaXPress、Camera Link，见 [Camera](/0107_Media_Image_Camera) |

表中：这是选型时需要核对的参数；接口带宽 = 分辨率 × 位深 × 帧率，应小于接口的实际可用带宽。
