# Control

机器人控制：根据期望运动与当前状态计算关节力矩。所属总览见 [RL
Robot](https://github.com/junxnone/aiwiki/issues/458)，运动学见 [RL Robot
Kinematics](https://github.com/junxnone/aiwiki/issues/768)。

## 控制框架

``` mermaid
flowchart LR
    R[期望 q_d] --> S((误差 e))
    S --> K[控制器]
    K -- 力矩 tau --> P[机器人]
    P -- 状态 q 与 q_dot --> S
```

图中：

  - 节点：期望轨迹 $q\_d$、误差 $e$、控制器、机器人（受动力学方程约束）
  - 箭头：控制器输出力矩 $\\tau$ 驱动机器人；机器人状态反馈回来与期望比较形成闭环
  - 关键结论：控制器设计的核心是从误差 $e=q\_d-q$ 得到合适的 $\\tau$

## 独立关节 PID

$$ \\tau = K\_p,e + K\_d,\\dot{e} + K\_i\\int e,dt $$

其中：

  - $e=q\_d-q$：位置误差；$\\dot{e}$：速度误差
  - $K\_p$：比例增益，增大则响应快但易振荡
  - $K\_d$：微分增益，提供阻尼，抑制超调
  - $K\_i$：积分增益，消除稳态误差，过大则易积分饱和
  - 特点：简单，工业机器人最常用，但把每个关节当作独立系统，忽略耦合与重力，高速或负载变化时精度下降

重力补偿 PD：

$$ \\tau=K\_p,e+K\_d,\\dot{e}+g(q) $$

其中 $g(q)$ 为重力项（见 Dynamics）。可保证稳态误差为 0，且在全局渐近稳定。

## 计算力矩控制

利用动力学模型把非线性系统「线性化」：

$$
\\tau=M(q)\\left(\\ddot{q}\_d+K\_d,\\dot{e}+K\_p,e\\right)+C(q,\\dot{q})\\dot{q}+g(q)
$$

其中：

  - $\\ddot{q}\_d$：期望加速度（前馈）
  - $K\_p,K\_d$：正定对角增益矩阵
  - $M,C,g$：动力学模型（见 Dynamics）；用 RNEA 实时计算
  - 代入动力学方程后得误差方程 $\\ddot{e}+K\_d\\dot{e}+K\_p e=0$：线性、解耦，选好增益即可任意配置极点
  - 局限：模型必须足够准确，参数误差会破坏线性化效果；可进一步用自适应或鲁棒控制补偿

## 任务空间控制

直接在末端空间控制，期望是末端位姿 $x\_d$：

$$
F=\\Lambda(q)\\left(\\ddot{x}\_d+K\_d,\\dot{\\tilde{x}}+K\_p,\\tilde{x}\\right)+\\mu(q,\\dot{q})+p(q),\\qquad
\\tau=J^{\\top}F $$

其中：

  - $\\tilde{x}=x\_d-x$：末端位姿误差
  - $\\Lambda=(JM^{-1}J^{\\top})^{-1}$：任务空间惯量矩阵
  - $\\mu,p$：任务空间的科氏项和重力项
  - $J^{\\top}F$：把末端力映射成关节力矩
  - 冗余机械臂可在零空间 $(I-J^{+}J)$ 中加次级任务（如避关节限位）

## 阻抗与力控制

接触任务（打磨、装配、人机协作）中，机器人需要「柔顺」：

$$
M\_d,\\ddot{\\tilde{x}}+D\_d,\\dot{\\tilde{x}}+K\_s,\\tilde{x}=F\_{ext}
$$

其中：

  - $M\_d,D\_d,K\_s$：期望的虚拟质量、阻尼、刚度，决定末端表现得像质量-弹簧-阻尼系统
  - $F\_{ext}$：环境作用于末端的外力
  - 刚度小：碰撞时更柔，但跟踪精度低；刚度大：更硬，精度高
  - 其他：导纳控制（力输入、运动输出）、混合位置/力控制

## 方法对比

| 方法       | 需要模型       | 优点     | 缺点         |
| -------- | ---------- | ------ | ---------- |
| 独立关节 PID | 否          | 简单、鲁棒  | 忽略耦合，高速精度低 |
| 重力补偿 PD  | 只需 $g(q)$  | 稳定性有保证 | 动态跟踪一般     |
| 计算力矩     | 完整模型       | 线性化、解耦 | 依赖模型精度     |
| 任务空间控制   | 完整模型 + $J$ | 直接控制末端 | 需处理奇异性     |
| 阻抗控制     | 模型 + 力感知   | 接触安全   | 参数整定复杂     |

表中：

  - **需要模型**：是否依赖动力学模型
  - 对比结论：无模型/低成本用 PID，高性能轨迹跟踪用计算力矩，接触和人机交互用阻抗控制

## 与强化学习的关系

强化学习用神经网络策略 $\\pi\_\\theta(a\\mid s)$ 取代手工设计的控制器：状态 $s$ 为 $q,\\dot{q}$
等，动作 $a$ 可以是关节力矩或目标位置（再由底层 PD 控制器执行）。常见实践是「RL 输出目标位置 + 底层
PD」，兼具学习的灵活与经典控制的稳定性。
